<Info>
  Les **Alter Actions** sont des workflows d'IA personnalisables qui vous permettent de créer des assistants spécialisés pour des tâches spécifiques. Combinez les instructions de l'IA, les déclencheurs vocaux, les Tools et l'exécution conditionnelle pour automatiser tout sur votre Mac.
</Info>

## Qu'est-ce qu'une Alter Action ?

Une **Alter Action** est une automatisation avancée qui combine :

- **Instructions IA** — Invites système définissant le comportement de l'IA
- **Déclencheurs** — Commandes vocales, raccourcis clavier ou exécution conditionnelle
- **Contexte** — Accès au texte sélectionné, aux fichiers et aux applications actives
- **Tools** — Intégrations configurées avec votre Mac et plus de 2 000 services externes
- **Sortie** — Affichage des résultats (markdown, code, insertion en ligne)

Considérez une Alter Action comme un « assistant IA spécialisé » personnalisé pour une tâche précise.

## Ouvrir l'Action Editor

### Méthode 1 : barre de menus (la plus rapide)
1. Cliquez sur l'**icône Alter** dans la barre de menus (en haut à droite)
2. Sélectionnez **Action Editor**

![Barre de menus](/images/tools/menu-bar-action-editor.webp)

### Méthode 2 : menu Options
1. Ouvrez la fenêtre Alter
2. Cliquez sur **⋯** (trois points) en haut à droite
3. Sélectionnez **Action Editor**

![Menu d'options](/images/tools/options-menu-action-editor.webp)

### Méthode 3 : raccourci clavier
Appuyez sur **⌘⇧E** (Commande + Maj + E) pour ouvrir directement l'Action Editor

<Tip>
  Le raccourci clavier est la méthode la plus rapide une fois mémorisé.
</Tip>

## Parcours de l'Action Editor

L'Action Editor comporte 8 sections principales, chacune contrôlant un aspect différent de votre action. Utilisez le panneau de gauche pour naviguer entre les onglets.

### 1. Paramètres généraux

Configurez les métadonnées de base et le contexte d'exécution.

![Onglet Général](/images/tools/action-editor-01-general.webp)

**Champs :**
- **Nom** — Nom lisible de l'action (par ex. « Code Explainer »)
- **Description** — Ce que fait cette action (facultatif)
- **Catégorie** — Organisez les actions par type (code, productivité, métier, etc.)
- **Workspace** — Attribuez à un Workspace spécifique (facultatif)
- **Inclure le profil** — Inclure les informations de profil utilisateur dans le contexte de l'IA

**Options de visibilité :**
- **Show only when running** — L'action n'apparaît que si une application est en cours d'exécution
- **Show only when active** — L'action n'apparaît que si une application a le focus
- **Workspace context** — Choisissez quel(s) Workspace(s) voient cette action

<Note>
  Chaque action reçoit automatiquement un UUID unique.
</Note>

### 2. System Prompt

Définissez les instructions IA et les paramètres pour le modèle.

![Onglet System Prompt](/images/tools/action-editor-02-systemprompt.webp)

**System Prompt** — Instructions principales décrivant le comportement et l'expertise de l'IA.

**Exemple :**
```
# IDENTITY AND PURPOSE
You are an expert software engineer who explains code clearly
and accessibly to developers of all skill levels.

# STEPS
1. Analyze the provided code
2. Identify its purpose and key components
3. Explain each section in simple terms

# OUTPUT INSTRUCTIONS
- Use markdown formatting
- Include code examples where helpful
- Keep language clear and non-technical
```

**Parameters** — Définissez les champs de saisie que les utilisateurs peuvent personnaliser avant l'exécution (texte, listes déroulantes, etc.).

### 3. User Prompt

Modèle de l'invite utilisateur envoyée à l'IA.

![Onglet User Prompt](/images/tools/action-editor-03-userprompt.webp)

**Utilisation des variables de contexte :**

Encadrez les variables avec `{{ }}` pour insérer du contenu dynamique :

```
Please explain this code:

{{ textSelection }}

Explanation detail: {{ detailLevel }};
```

**Variables de contexte disponibles :**
- `{{ textSelection }}` — Texte actuellement sélectionné
- `{{ filePath }}` — Chemin du fichier sélectionné
- `{{ clipboard }}` — Contenu du presse-papiers
- Paramètres personnalisés définis dans System Prompt

### 4. Quand afficher

Contrôlez quand et où cette action apparaît.

![Onglet Quand afficher](/images/tools/action-editor-04-whentoshow.webp)

**Conditions de visibilité :**

- **Installed Applications** — Afficher l'action uniquement dans certaines apps (VSCode, Xcode, Safari, etc.)
- **Application is running** — L'action exige que l'app soit en cours d'exécution
- **Application has focus** — L'action ne fonctionne que lorsque l'app est au premier plan
- **Web browser tab contains** — Afficher l'action lors de la navigation sur certains domaines
- **Has content** — Afficher l'action uniquement lorsque le contexte est disponible

### 5. Automation

Configurez le comportement d'exécution, les planifications et le traitement en arrière-plan.

![Onglet Automation](/images/tools/action-editor-05-automation.webp)

**Champs :**

- **Background Job** — Exécuter l'action en arrière-plan sans afficher l'interface
- **Schedules** — Exécuter l'action à des moments précis (par ex. « Chaque lundi à 9 h »)
- **Quick Action** — Exécuter automatiquement la prochaine « Quick Action » une fois celle-ci terminée

Utilisez ceci pour enchaîner les actions : première action → sortie → la suivante s'exécute automatiquement.

### 6. Tools

Limitez les Tools disponibles pour cette action.

![Onglet Tools](/images/tools/action-editor-06-tools.webp)

**Configuration des Tools :**

- **Disable Tools** — Désactivez des Tools individuelles pour restreindre les fonctionnalités
- Lorsque vide : toutes les Tools sont disponibles
- Lorsque configuré : seules les Tools sélectionnées sont disponibles

**Ask Anything par défaut (beta100+) :** L'action intégrée **Ask Anything** active **Flow**, **Computer Use** et **Ask User** dès le départ. Personnalisez-la ou dupliquez-la si vous souhaitez un ensemble de Tools plus restreint.

**Memory :** Liez le Tool **Memory** lorsqu'une action doit lire des faits enregistrés ou rechercher des chats et réunions antérieurs. Memory n'est pas activée pour toutes les actions par défaut. Voir [Memory](/fr/workflows/memory) et [Gérer Memory](/fr/how-to/manage-memory).

L'action intégrée **Memory Catch-Up** inclut Memory déjà liée. C'est le moyen fiable d'Alter pour amorcer Memory à partir des 30 derniers jours de chats et réunions — recommandé lorsque vous activez Memory pour la première fois ou souhaitez compléter l'historique récent. Voir [Memory Catch-Up](/fr/workflows/memory-catch-up).

**Coding tools (post-beta106) :** Le chemin le plus rapide est un [agent de coding Marketplace](/fr/workflows/coding-tools#get-started-from-the-marketplace-recommended) — téléchargez depuis **Tools Manager → Marketplace → Browse** (par exemple le [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent) en ligne) et exécutez-le une fois ; Alter active l'intégration de coding requise à la première utilisation. En alternative, sous **Local Tools → Coding**, connectez **ChatGPT**, **Cursor**, **OpenCode** et/ou **Claude** dans **Tools Manager** d'abord, puis limitez les fournisseurs que chaque action peut utiliser — par exemple une action de release peut activer **Cursor** uniquement. Les sessions de coding s'exécutent de façon asynchrone ; les résultats reviennent dans la conversation d'origine. Voir [Coding tools](/fr/workflows/coding-tools).

**Pourquoi limiter les Tools ?**
- Réduire la charge de décision de l'IA (se concentrer sur les Tools pertinentes)
- Accélérer l'exécution de l'action
- Renforcer la sécurité (limiter ce à quoi les actions peuvent accéder)

### 7. Model

Sélectionnez le modèle IA, le niveau de réflexion et le degré de créativité.

![Onglet Model](/images/tools/action-editor-07-model.webp)

**Champs :**

- **Model** — Sélecteur recherchable regroupé en **Current**, **Favorites** et **Other models**. Laissez vide pour utiliser le modèle par défaut de l'utilisateur, ou épinglez un modèle spécifique pour cette action.
  - Chaque ligne affiche la longueur de contexte, la prise en charge de la vision et les favoris
  - Lorsque le modèle le permet, ajustez **Thinking effort** (**Low**, **Balanced**, **Max**) en ligne

- **Temperature** — Ajustez la créativité par rapport à la précision
  - **0,0** — Déterministe (cohérent, prévisible)
  - **0,5** — Équilibré (par défaut)
  - **1,0** — Créatif (imprévisible, exploratoire)

Alter mémorise le thinking effort **par modèle** dans le Hub, QuickHub et l'Action Editor.

<Tip>
  Utilisez **⌘F** dans la barre latérale de l'Action Editor pour rechercher des actions. Cliquez sur l'icône de filtre pour restreindre par tâches d'arrière-plan, planifications, avertissements, actions modifiées ou **Folders** (catégories d'actions). Les filtres de dossiers incluent les raccourcis **All** et **None**.
</Tip>

### 8. Gateways

Choisissez les connexions Gateway exactes qui peuvent utiliser cette action. Chaque Gateway Buzz, Discord et Telegram configuré a son propre interrupteur, de sorte que deux comptes sur la même plateforme peuvent avoir des accès différents.

<Info>
  **Buzz gateway (internal)** — Buzz n'apparaît que dans les builds Alter internes pour l'équipe de développement. Voir [Buzz gateway (internal)](/apps-tools/gateways-buzz).
</Info>

**Disponibilité** — Interrupteurs Gateway :

| Réglage | Effet |
|---------|--------|
| Tous les interrupteurs désactivés | Local uniquement (Hub, QuickHub, etc.) |
| Un Gateway activé | Disponible uniquement depuis cette connexion Gateway nommée |
| Plusieurs Gateways activés | Disponible depuis exactement ces connexions, même sur plusieurs plateformes |
| Tous les interrupteurs activés | Disponible depuis chaque Gateway actuellement configuré |

L'action intégrée **Ask Anything** apparaît initialement sur tous les Gateways compatibles. Les actions personnalisées restent locales jusqu'à ce que vous activiez un ou plusieurs interrupteurs Gateway. Modifier un interrupteur enregistre une liste explicite de connexions Gateway, de sorte qu'un Gateway ajouté ultérieurement n'hérite pas automatiquement de cette action.

Sur les Gateways, les **actions sans paramètres** (sans champs de saisie) s'exécutent immédiatement lorsqu'elles sont choisies dans **Choose action** ; les **actions paramétrées** attendent le message suivant de l'utilisateur.

**Livraison programmée via Gateway** — Lorsqu'une action s'exécute selon un planning, activez **Démarrer les conversations planifiées sur un Gateway**, choisissez un Gateway **Discord**, **Telegram** ou **Buzz** *(interne)* activé, puis sélectionnez une **Destination** (canal, chat ou stream Buzz). Alter y publie la réponse d'ouverture de l'action au lieu de l'exécuter uniquement en local. Les Gateways Buzz peuvent aussi définir une **Default scheduled destination** dans **Préférences → Integrations → Gateways**.

Voir [Gateways](/fr/apps-tools/gateways) pour la configuration, les commandes de chat, la livraison programmée et les réglages Gateway.

## Exemples d'actions courantes

### Exemple 1 : Code Explainer

**Configuration :**
- **Nom :** Explain Code
- **Catégorie :** code
- **Installed Apps :** VSCode, Xcode
- **System Prompt :** You are an expert programmer who explains code clearly
- **User Prompt :** `Please explain this code:\n\n{{ textSelection }}`
- **Consumer :** markdown
- **Temperature :** 0,5

### Exemple 2 : Créateur de brouillon d'e-mail

**Configuration :**
- **Nom :** Draft Email
- **Catégorie :** productivity
- **Quand afficher :** Application Mail active
- **System Prompt :** You are a professional business communicator
- **User Prompt :** `Transform this into a professional email:\n\n{{ textSelection }}`
- **Tools :** Activer uniquement Mail
- **Consumer :** in-place
- **Temperature :** 0,6

### Exemple 3 : Brief quotidien programmé

**Configuration :**
- **Nom :** Daily Brief
- **Catégorie :** productivity
- **Automation :** Planification quotidienne à 9 h 00
- **Background Job :** Activé
- **System Prompt :** Generate a daily brief of priorities

## Déclencheurs vocaux

Attribuez des raccourcis vocaux pour déclencher des actions en mains libres :

<Steps>
  <Step title="Paramètres">
    Allez dans **Préférences > Déclencheurs vocaux**
  </Step>
  <Step title="Ajouter un déclencheur">
    Cliquez sur **+ Add Trigger**
  </Step>
  <Step title="Sélectionner une action">
    Choisissez l'action dans la liste déroulante
  </Step>
  <Step title="Attribuer une phrase">
    Saisissez la phrase de déclenchement (par ex. « explain » pour Code Explainer)
  </Step>
  <Step title="Enregistrer">
    Cliquez sur Save et vous êtes prêt
  </Step>
</Steps>

**Utilisation :** Maintenez le raccourci vocal + prononcez la phrase de déclenchement → l'action s'exécute avec le contexte actuel

## Intégration x-callback-url

Déclenchez des Alter Actions depuis **n'importe quelle application** à l'aide d'URL spéciales. Cela permet de puissants workflows d'automatisation inter-applications.

### Qu'est-ce que x-callback-url ?

x-callback-url est un protocole de communication inter-applications qui permet aux applications de déclencher des actions les unes dans les autres via des URL formatées.

- **Entrant** — Déclenchez des Alter Actions depuis d'autres apps (Raccourcis, Notes, Safari, etc.)
- **Sortant** — Créez des liens dans Alter qui ouvrent d'autres apps (Bear, OmniFocus, Drafts, etc.)

### Obtenir l'URL Callback de votre action

<Steps>
  <Step title="Ouvrir l'Action Editor">
    Appuyez sur **⌘⇧E**
  </Step>
  <Step title="Sélectionner une action">
    Choisissez l'action que vous souhaitez exposer
  </Step>
  <Step title="Aller à General">
    Accédez à l'onglet General
  </Step>
  <Step title="Trouver URL Callback">
    Recherchez la section « URL Callback »
  </Step>
  <Step title="Copier l'URL">
    Copiez l'URL `alter://`
  </Step>
</Steps>

**Format :**
```
alter://action/{action-id}?input=VALUE&param2=VALUE
```

### Déclencher des Alter Actions depuis d'autres apps

**Exemple 1 : recherche Web depuis Safari**
```
alter://action/ask-web?input=What+is+Alter+MacOS
```

**Exemple 2 : Code Explainer avec entrée**
```
alter://action/explain-code?input=const+hello+%3D+%28%29+%3D%3E+%7B%7D
```

**Exemple 3 : utilisation dans Raccourcis Apple**
1. Créez un nouveau raccourci
2. Ajoutez l'action « Ouvrir l'URL »
3. Collez votre URL `alter://`
4. Exécutez le raccourci pour déclencher l'action

### Cas d'utilisation

  <Accordion icon="workflow" title="Automatisation de workflow">

## Dépannage

<AccordionGroup>
  <Accordion icon="circle-exclamation" title="L'action n'apparaît pas dans le menu">
    - Vérifiez les paramètres **Quand afficher**
    - Confirmez que l'app est en cours d'exécution/active (si configuré)
    - Assurez-vous que l'action est **activée**
  </Accordion>

  <Accordion icon="triangle-exclamation" title="L'action s'exécute mais produit un résultat médiocre">
    - Revoyez le **System Prompt** — soyez plus précis
    - Ajustez la **Temperature** (plus basse pour la précision, plus élevée pour la créativité)
    - Vérifiez le **User Prompt** — assurez-vous que les variables sont correctes
  </Accordion>

  <Accordion icon="microphone" title="Le déclencheur vocal ne fonctionne pas">
    - Vérifiez que le raccourci est configuré dans les Préférences
    - Contrôlez les autorisations du microphone
    - Testez d'abord avec un déclenchement manuel
  </Accordion>

  <Accordion icon="lock" title="Tools indisponibles dans l'action">
    - Allez dans l'onglet **Tools**
    - Vérifiez que les Tools ne sont pas désactivées
    - Contrôlez les autorisations système pour le Tool
  </Accordion>
</AccordionGroup>
