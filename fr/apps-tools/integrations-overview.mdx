Alter se connecte à votre Mac de deux façons :

- **Mac Apps (outils locaux)** — Intégrations first-party avec Mail, Calendar, Messages, Notes, Reminders, Contacts, Maps, DEVONthink, Computer Use et **Coding** (ChatGPT, Cursor, OpenCode, Claude Code). Elles s'exécutent sur votre Mac avec les permissions système ; pas de clés API tierces pour les apps intégrées.
- **Gateways** — Bots Discord et Telegram pour discuter avec Alter depuis ces plateformes pendant qu'Alter tourne sur votre Mac. Configurez dans **Préférences → Intégrations → Gateways**.
- **Intégrations externes** — Serveurs MCP, skills et connecteurs cloud (Slack, Notion, GitHub, APIs de recherche web, etc.) configurés dans **Tools Manager**.

## Choisir le bon type d'intégration

- Utilisez **Mac Apps** quand le flux reste sur votre Mac (tri de boîte mail, calendrier, iMessage, automatisation d'écran).
- Utilisez **Gateways** quand vous voulez parler à Alter depuis **Discord** ou **Telegram** sans ouvrir le Hub.
- Utilisez les **intégrations externes** quand les données ou actions sont dans un autre service ou sur le web.

## Coding tools {#coding-tools}

La catégorie **Coding** dans **Tools Manager → Local Tools** connecte Alter aux agents de coding locaux que vous exécutez déjà sur votre Mac :

- **ChatGPT** — tâches persistantes via l'app desktop ChatGPT (Codex)
- **Cursor** — sessions via Cursor Agent CLI
- **OpenCode** — sessions CLI et terminal, y compris le travail démarré en dehors d'Alter
- **Claude** — sessions Claude Code CLI

**Recommandé :** installez un agent spécialisé sur l'[Alter Marketplace](https://alterhq.com/marketplace) — le [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent) en ligne est disponible ; agents Cursor, Claude et OpenCode bientôt disponibles. À la première exécution, Alter active automatiquement l'outil de coding requis.

Alter démarre ces sessions en arrière-plan depuis le Hub ou une action et **ramène les résultats dans la même conversation**. Les coding tools utilisent un profil de permissions restreint mappé depuis le workspace — elles n'exigent pas **Full Access** d'Alter pour les dossiers de projet autorisés.

  <Step title="Activer seulement le nécessaire">

## Intégrations externes

Les intégrations externes connectent Alter à Slack, Notion, GitHub et APIs de recherche via **Tools Manager → Remote MCP Servers** ou skills installées.

- Utilisez-les quand votre flux couvre plusieurs systèmes hors des apps macOS intégrées.
- Activez uniquement les services requis pour la tâche en cours.
- Les flux Mac Apps (Mail, Calendar, Messages) **ne** nécessitent **pas** de connecteurs externes — voir **Mac Apps** dans cet onglet.
