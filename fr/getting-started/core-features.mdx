## Interagir avec vos applications

### AppSense - Comprendre votre Mac

AppSense lit les données directement depuis les applications macOS pour qu'Alter puisse travailler au-delà de ce qui est visible à l'écran.

Utilisez ce guide dédié :

- [Utiliser l'application actuelle et le mode Suivre](/fr/getting-started/use-current-app-and-follow-mode)

## Mode Suivre

Le mode Suivi garde votre contexte synchronisé pendant que vous continuez à travailler, afin que les réponses de suivi restent ancrées.

Utilisez ce guide dédié :

- [Utiliser l'application actuelle et le mode Suivre](/fr/getting-started/use-current-app-and-follow-mode)

## Interagir avec les fichiers et les dossiers

Vous pouvez glisser des fichiers et dossiers vers Alter, ajouter du contenu depuis des applications et poser des questions ancrées sur ce contenu.

## Alter Actions - Flux de travail

Les actions vous permettent d'enregistrer et de réutiliser des flux de prompts à forte valeur ajoutée avec contrôle des modèles et des outils. **Mes actions** combine une bibliothèque consultable, des contrôles en ligne modèle/planification/raccourci, un **chat de l'éditeur** pour les modifications en langage naturel et des **documents d'action** pour l'édition champ par champ.

Utilisez ces guides dédiés :

- [Créer des actions réutilisables](/fr/getting-started/actions-basics)
- [Alter Actions — Mes actions et chat de l'éditeur](/fr/workflows/alter-actions)

Gateways connectent Alter à **Discord** et **Telegram** pour exécuter des actions depuis ces apps de chat pendant qu'Alter reste sur votre Mac.

## Split Panel

Split Panel divise le Hub en deux volets de conversation pour rechercher dans l'un et rédiger dans l'autre. Le pontage de contexte — conversations, fichiers, extraits et pièces jointes — circule entre volets sans copier-coller.

Utilisez ce guide dédié :

- [Split Panel](/fr/getting-started/split-panel)

## Partager des conversations sur le Web

Publiez un chat Hub comme **lien public en lecture seule** sur alterhq.com pour que d'autres lisent le fil complet dans un navigateur — sans installer Alter. Copiez l'URL, **Mettez à jour** quand la discussion change ou **Supprimez** pour dépublier.

Connexion requise. Indisponible pour les discussions **Live Notepad** ou **Meeting Scribe** de réunion. Distinct de **Enregistrer la conversation en Markdown** (**⌘⇧S**) local et de [Partager la trace](/fr/workflows/share-task-traces) pour le support.

Utilisez ce guide dédié :

- [Partager des conversations sur le Web](/fr/workflows/share-conversations)

## Coding tools

Déléguez le travail d'implémentation à **ChatGPT**, **Cursor**, **OpenCode** ou **Claude Code** depuis la même conversation Alter. Alter exécute la session localement, affiche la progression dans des cartes de tâche et ramène le résultat lorsque le tour se termine.

Le moyen le plus rapide de démarrer est un **agent de coding Marketplace** — téléchargez depuis [alterhq.com/marketplace](https://alterhq.com/marketplace) et exécutez-le une fois ; Alter active l'outil de coding lié à la première utilisation.

Utilisez ce guide dédié :

- [Coding tools](/fr/workflows/coding-tools)

## Recherche, filtres et Thinking effort

**Rechercher et filtrer** — Trouvez du texte dans une conversation ouverte (**⌘F**), parcourez tout l'historique du Hub (**⇧⌘F**), filtrez la barre latérale par type de conversation, workspace, action ou tag, et naviguez dans les longs fils Hub avec le turn index.

**Thinking effort** — Sur les modèles pris en charge, choisissez **Low**, **Balanced** ou **Max** depuis le sélecteur de modèle ou l'Éditeur d'Action. Alter mémorise le choix par modèle et préserve le contexte de raisonnement d'un tour à l'autre.

Utilisez ces guides dédiés :

- [Types de fenêtres — Rechercher et filtrer les conversations](/fr/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [Choisir votre modèle génératif — Thinking effort](/fr/how-to/choose-generative-model#thinking-effort)

## Memory

Memory enregistre des faits concis entre chats, workspaces et réunions, puis rappelle les plus pertinents dans de nouvelles conversations.

**Nouveau sur Memory ?** Commencez par [Memory Catch-Up](/fr/workflows/memory-catch-up). Dans un nouveau chat Hub, choisissez **Donner une longueur d'avance à Memory** pour examiner les 30 derniers jours de chats et réunions et amorcer Memory en une passe — bien plus rapide qu'attendre que l'apprentissage quotidien rattrape.

Utilisez ces guides dédiés :

- [Memory Catch-Up](/fr/workflows/memory-catch-up) — première étape recommandée pour alimenter Memory depuis l'historique
- [Memory](/fr/workflows/memory) — recall, apprentissage et Tool Memory
- [Gérer Memory](/fr/how-to/manage-memory) — revue, oubli et réglages
