Utilisez des actions lorsque vous répétez le même modèle de tâche et souhaitez une qualité de sortie constante.

## Ce que vous apporte une action

<CardGroup cols={3}>
  <Card title="Reusable prompts" icon="repeat">
    Exécutez le même flux de travail sans réécrire les instructions à chaque fois.
  </Card>
  <Card title="Model choice" icon="brain">
    Attribuez le meilleur modèle pour chaque tâche.
  </Card>
  <Card title="Tool control" icon="sliders-horizontal">
    Activez uniquement les outils nécessaires pour des exécutions plus sûres et plus rapides.
  </Card>
</CardGroup>

## Créez votre première action

<Steps>
  <Step title="Ouvrir Mes actions">
    Appuyez sur **⌘⇧E**, ou ouvrez **Outils et actions** (**⌘⇧T**) et sélectionnez **Mes actions**.
  </Step>
  <Step title="Create or duplicate">
    Décrivez une nouvelle action dans le **chat de l'éditeur**, cliquez sur **+** dans la barre d'outils, ou dupliquez une action intégrée avant de la personnaliser.
  </Step>
  <Step title="Set clear instructions">
    Définissez un résultat concret, tel qu'un résumé hebdomadaire, des notes de version ou un tri dans la boîte de réception — dans le chat ou dans le document d'action.
  </Step>
  <Step title="Save and run">
    Testez avec une seule entrée réelle et affinez la formulation si nécessaire.
  </Step>
</Steps>

<Note>
  Les actions intégrées sont en lecture seule. Dupliquez-les pour personnaliser le comportement.
</Note>

## Choisissez un modèle et des outils par action

Utilisez les sections **Modèle** et **Outils** du document d'action, les contrôles en ligne dans Mes actions, ou le chat de l'éditeur pour attribuer un modèle et un accès aux outils.

- Choisissez des modèles locaux pour les tâches sensibles.
- Choisissez des modèles plus rapides pour les tâches lourdes d'automatisation.
- Commencez avec un minimum d'outils, puis ajoutez uniquement ce dont votre flux de travail a besoin.

## Ask Anything — l'action par défaut

Lorsque vous tapez dans l'invite sans choisir une autre action, Alter exécute **Ask Anything**. Depuis **2.0.0-beta100**, il inclut **Flow**, **Computer Use** et **Ask User** par défaut afin que les invites quotidiennes puissent orchestrer des outils, automatiser l'écran ou poser des questions de clarification.

Pour personnaliser : appuyez sur **⌘⇧E** → sélectionnez **Ask Anything** → ouvrez son document (**Modifier** ou double-clic) → **Tools**. Dupliquez Ask Anything si vous voulez une variante sans modifier l'action intégrée par défaut.

Voir [Utiliser Flow pour l'orchestration des outils](/fr/workflows/use-flow-orchestration#ask-anything-defaults-beta100) pour le rôle de Flow dans la configuration par défaut.
