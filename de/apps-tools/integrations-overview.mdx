Alter verbindet sich auf zwei Arten mit Ihrem Mac:

- **Mac Apps (lokale Tools)** — First-Party-Integrationen mit Mail, Calendar, Messages, Notes, Reminders, Contacts, Maps, DEVONthink und Computer Use. Laufen auf Ihrem Mac mit Systemberechtigungen; keine API-Keys für eingebaute Apps.
- **Externe Integrationen** — MCP-Server, Skills und Cloud-Connectors (Slack, Notion, GitHub, Web-Search-APIs usw.) im **Tools Manager**.

## Den richtigen Integrationstyp wählen

- **Mac Apps** nutzen, wenn der Workflow auf Ihrem Mac bleibt (Posteingang, Kalender, iMessage, Bildschirmautomatisierung).
- **Externe Integrationen**, wenn Daten oder Aktionen in einem anderen Dienst oder im offenen Web liegen.

## Lokale Tools (Mac Apps)

Lokale Tools laufen in Ihrer Umgebung und eignen sich für tägliche Arbeit mit Apple-Apps und Computer Use.

### Lokale Tools aktivieren

<Steps>
  <Step title="Tools Manager öffnen">
    In Alter: Drei-Punkte-Menü → **Tools Manager**.
  </Step>
  <Step title="Nur das Nötige aktivieren">
    Relevante lokale Tools für Ihren Workflow einschalten.
  </Step>
  <Step title="Mit einem Prompt testen">
    Kleinen Prompt ausführen, um Berechtigungen und Verhalten zu prüfen.
  </Step>
</Steps>

## Externe Integrationen

Externe Integrationen verbinden Alter mit Slack, Notion, GitHub und Recherche-APIs über **Tools Manager → Remote MCP Servers** oder installierte Skills.

- Diese nutzen, wenn Ihr Workflow mehrere Systeme außerhalb der macOS-Built-ins umfasst.
- Nur die für die aktuelle Aufgabe nötigen Dienste aktivieren.
- Mac-App-Workflows (Mail, Calendar, Messages) brauchen **keine** externen Connectors — siehe **Mac Apps** in diesem Tab.
