## Ziel

Verbinden und verwalten Sie Integrationen sicher mit klaren Schritten zur Fehlerbehebung.

Alter fasst Tools und Aktionen in einem Fenster zusammen: **Tools & Aktionen** (**⌘⇧T**). Nutzen Sie es für Marketplace-Agenten, Aktive Tools, Quick Actions, Skills, Remote MCP und **Meine Aktionen** — die Aktionsliste und den Editor-Chat zum Erstellen von Workflows.

</Card>

## Schritte

1. Drücken Sie **⌘⇧T**, um **Tools & Aktionen** zu öffnen, oder öffnen Sie **Einstellungen** für integrationsbezogene Voreinstellungen.
2. Verbinden Sie jeweils eine Integration und testen Sie sofort.
3. Bestätigen Sie erforderliche Berechtigungen und Kontobereiche.
4. Erstellen Sie eine einfache Testaufforderung, um das erwartete Verhalten zu überprüfen.
5. Bei Fehlern prüfen Sie die Anbieterauthentifizierung und versuchen Sie es erneut.

## Viele Tools verwalten

Das Aktivieren vieler Tools erhöht die Nutzung des Kontextfensters und beeinträchtigt die Leistung. Für die meisten Workflows verwenden Sie **Flow** – Alters Tool-Orchestrator, der automatisch das richtige Tool für jede Anfrage auswählt.

<Card title="Flow für Tool-Orchestrierung nutzen" icon="wand-magic-sparkles" href="/de/workflows/use-flow-orchestration">
  Flow reduziert die Kontextnutzung, indem es als einzelnes Tool fungiert, das Anfragen automatisch an die passende Integration weiterleitet.
</Card>

Anstatt alle Tools in jede Anfrage zu laden, analysiert Flow:
- Ihre Anfrage und wählt das richtige Tool
- Mehrstufige Orchestrierung über Tools hinweg
- Reduzierte Kontextfensternutzung und bessere Leistung

Aktivieren Sie Flow in **Tools & Aktionen** unter **Local Tools > Alter**.

## Coding tools

**Tools & Aktionen → Local Tools → Coding** listet vier lokale Coding-Integrationen:

| Anbieter | Verbinden, wenn |
|----------|--------------|
| **ChatGPT** | Sie die ChatGPT-Desktop-App für agentisches Coding nutzen |
| **Cursor** | Sie Cursor Agent CLI (`agent`) installiert haben |
| **OpenCode** | Sie OpenCode CLI nutzen, einschließlich Terminal-Sitzungen |
| **Claude** | Sie Claude Code (`claude`) im Terminal nutzen |

**Schnellster Weg:** Installieren Sie einen spezialisierten Agenten von **[Marketplace → Browse](https://alterhq.com/marketplace)** — zum Beispiel den live [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent). Beim ersten Lauf fordert Alter Sie auf, die verknüpfte Coding-Integration zu aktivieren. Siehe [Coding tools — Marketplace-Onboarding](/de/workflows/coding-tools#get-started-from-the-marketplace-recommended).

Verbinden Sie nur die Anbieter, die Sie benötigen. Jeder stellt run-, list-, control- und settings-Tools für Alters Modell bereit, wenn er für die aktuelle Aktion aktiviert ist.

## Fehlerbehebung

- Authentifizieren Sie die Anbieterverbindung erneut.
- Bestätigen Sie lokale/Netzwerkberechtigungen.
- Prüfen Sie integrationsspezifische Limits und Kontingente.
