Verwenden Sie Aktionen, wenn Sie dasselbe Aufgabenmuster wiederholen und eine konsistente Ausgabequalität wünschen.

## Was eine Aktion dir gibt

<CardGroup cols={3}>
  <Card title="Reusable prompts" icon="repeat">
    Führen Sie denselben Workflow aus, ohne die Anweisungen jedes Mal neu schreiben zu müssen.
  </Card>
  <Card title="Model choice" icon="brain">
    Weisen Sie jeder Aufgabe das beste Modell zu.
  </Card>
  <Card title="Tool control" icon="sliders-horizontal">
    Aktivieren Sie nur die Tools, die für sicherere und schnellere Läufe erforderlich sind.
  </Card>
</CardGroup>

## Erstellen Sie Ihre erste Aktion

<Steps>
  <Step title="Meine Aktionen öffnen">
    Drücken Sie **⌘⇧E**, oder öffnen Sie **Tools & Aktionen** (**⌘⇧T**) und wählen Sie **Meine Aktionen**.
  </Step>
  <Step title="Create or duplicate">
    Beschreiben Sie eine neue Aktion im **Editor-Chat**, klicken Sie auf **+** in der Symbolleiste, oder duplizieren Sie eine integrierte Aktion, bevor Sie sie anpassen.
  </Step>
  <Step title="Set clear instructions">
    Definieren Sie ein konkretes Ergebnis, z. B. eine wöchentliche Zusammenfassung, Versionshinweise oder eine Sortierung im Posteingang — im Chat oder im Aktionsdokument.
  </Step>
  <Step title="Save and run">
    Testen Sie mit einer echten Eingabe und verfeinern Sie den Wortlaut bei Bedarf.
  </Step>
</Steps>

<Note>
  Integrierte Aktionen sind schreibgeschützt. Duplizieren Sie sie, um das Verhalten anzupassen.
</Note>

## Wählen Sie pro Aktion ein Modell und Tools aus

Verwenden Sie die Abschnitte **Modell** und **Tools** im Aktionsdokument, Inline-Steuerelemente in Meine Aktionen oder den Editor-Chat, um Modell- und Toolzugriff zuzuweisen.

- Wählen Sie lokale Modelle für sensible Aufgaben.
- Wählen Sie schnellere Modelle für automatisierungsintensive Aufgaben.
- Beginnen Sie mit minimalen Tools und fügen Sie dann nur das hinzu, was Ihr Workflow benötigt.

## Ask Anything — die Standard-Action

Wenn Sie in der Eingabeaufforderung tippen, ohne eine andere Aktion zu wählen, führt Alter **Ask Anything** aus. Seit **2.0.0-beta100** enthält es standardmäßig **Flow**, **Computer Use** und **Ask User**, damit alltägliche Eingaben Tools orchestrieren, den Bildschirm automatisieren oder Klärungsfragen stellen können.

Anpassen: **⌘⇧E** drücken → **Ask Anything** auswählen → Dokument öffnen (**Bearbeiten** oder Doppelklick) → **Tools**. Duplizieren Sie Ask Anything, wenn Sie eine Variante ohne Änderung der integrierten Standardaktion wünschen.

Siehe [Flow für Tool-Orchestrierung nutzen](/de/workflows/use-flow-orchestration#ask-anything-defaults-beta100), wie Flow in die Standardkonfiguration passt.
