## Split Panel

Split Panel teilt den Hub in zwei Konversationsbereiche, damit Sie in einem recherchieren und im anderen schreiben können. Kontext-Bridging — Konversationen, Dateien, Snippets und Anhänge — fließt zwischen den Bereichen ohne Copy-Paste.

Nutzen Sie diesen fokussierten Leitfaden:

- [Split Panel](/de/getting-started/split-panel)

## Konversationen im Web teilen

Veröffentlichen Sie einen Hub-Chat als **öffentlichen schreibgeschützten Link** auf alterhq.com, damit andere den vollständigen Thread im Browser lesen können — ohne Alter-Installation. URL kopieren, **Aktualisieren**, wenn sich die Diskussion ändert, oder **Entfernen**, um die Veröffentlichung aufzuheben.

Anmeldung erforderlich. Nicht verfügbar für **Live Notepad**- oder **Meeting Scribe**-Besprechungsdiskussionen. Getrennt von lokalem **Konversation als Markdown speichern** (**⌘⇧S**) und von [Trace teilen](/de/workflows/share-task-traces) für Support-Uploads.

Nutzen Sie diesen fokussierten Leitfaden:

- [Konversationen im Web teilen](/de/workflows/share-conversations)

## Coding tools

Delegieren Sie Implementierungsarbeit an **ChatGPT**, **Cursor**, **OpenCode** oder **Claude Code** aus derselben Alter-Konversation. Alter führt die Sitzung lokal aus, zeigt Fortschritt in Task-Karten und liefert das Ergebnis zurück, wenn der Turn abgeschlossen ist.

Der schnellste Einstieg ist ein **Marketplace-Coding-Agent** — von [alterhq.com/marketplace](https://alterhq.com/marketplace) herunterladen und einmal ausführen; Alter aktiviert das verknüpfte Coding-Tool bei der ersten Nutzung.

Nutzen Sie diesen fokussierten Leitfaden:

- [Coding tools](/de/workflows/coding-tools)

## Suche, Filter und Thinking effort

**Suchen und filtern** — Text in einer offenen Konversation finden (**⌘F**), gesamte Hub-Historie durchsuchen (**⇧⌘F**), Seitenleiste nach Konversationstyp, Workspace, Aktion oder Tag filtern und lange Hub-Threads mit dem Turn-Index durchspringen.

**Thinking effort** — Bei unterstützten Modellen **Low**, **Balanced** oder **Max** im Modellumschalter oder Aktionseditor wählen. Alter merkt sich die Wahl pro Modell und bewahrt Reasoning-Kontext über Folgeturns.

Nutzen Sie diese fokussierten Leitfäden:

- [Fenstertypen — Konversationen suchen und filtern](/de/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [Generatives Modell wählen — Thinking effort](/de/how-to/choose-generative-model#thinking-effort)

## Memory

Memory speichert prägnante Fakten über Chats, Workspaces und Meetings hinweg und ruft die relevantesten in neuen Konversationen ab.

**Neu bei Memory?** Starten Sie mit [Memory Catch-Up](/de/workflows/memory-catch-up). In einem neuen Hub-Chat wählen Sie **Memory einen Vorsprung geben**, um die letzten 30 Tage Chats und Meetings zu prüfen und Memory in einem Durchgang zu füllen — deutlich schneller als auf alltägliches Lernen zu warten.

Nutzen Sie diese fokussierten Leitfäden:

- [Memory Catch-Up](/de/workflows/memory-catch-up) — empfohlener erster Schritt, Memory aus der Historie zu speisen
- [Memory](/de/workflows/memory) — Abruf, Lernen und Memory-Tool
- [Memory verwalten](/de/how-to/manage-memory) — prüfen, vergessen und Einstellungen anpassen
