## Steps

1. Open Settings with `Cmd+,`.
2. Go to **Shortcuts → Global**.
3. Click **Open QuickHub** (or **Open notch** if QuickHub Mode is off) and press your new key combination.

The default is **⌘⇧Space**. If you previously used Alt+Space, that was a custom choice — reset to the default here if needed.
