<Info>
  **Memory Catch-Up** es la forma más rápida de empezar a alimentar Memory. Revisa tu actividad reciente en Alter, la compara con lo que ya está guardado y añade o actualiza solo los hechos duraderos que merece la pena conservar, sin pedirte aprobación por cada uno.
</Info>

## Por qué Catch-Up es el mejor primer paso

La Memory diaria aprende poco a poco, con un solo hecho candidato por respuesta completada de Ask Anything. Eso funciona bien cuando Memory ya tiene contexto, pero resulta lento si empiezas desde cero.

**Memory Catch-Up** resuelve ese problema de arranque. En una sola ejecución:

- Escanea los **últimos 30 días naturales** de chats personales y transcripciones de reuniones
- Incluye el **workspace actual** cuando hay uno activo
- Compara los candidatos con la Memory guardada antes de escribir nada
- Guarda automáticamente los hechos de alta confianza como una Alter Action de confianza

Piensa en Catch-Up como llenar el cuaderno por primera vez. La Memory diaria se encarga después de mantenerlo al día.

## Cuándo usarlo

Ejecuta Memory Catch-Up cuando:

- Acabas de activar **Use Memory** y quieres darle ventaja a Memory
- **Settings → Memory** está vacío pero ya tienes semanas de actividad en Alter
- Vuelves después de una pausa y quieres capturar objetivos, decisiones y preferencias recientes
- Has cambiado a un workspace nuevo y quieres contexto del proyecto a partir del trabajo reciente
- Si no, acabarías pegando el mismo contexto en cada chat nuevo

Catch-Up es un relleno puntual de los **últimos 30 días naturales**, no un indexador continuo en segundo plano. Puedes ejecutarlo otra vez más adelante si quieres otro refresco de 30 días.

## Cómo iniciar Catch-Up

<Steps>
  <Step title="Abrir un chat nuevo del Hub">
    Abre el Hub y crea una **nueva pestaña de conversación**. Catch-Up se ofrece en un chat vacío, no a mitad de un hilo.
  </Step>
  <Step title="Elegir la sugerencia">
    Selecciona **Dar ventaja a Memory** entre las sugerencias de bienvenida. Aparece como una tarjeta recomendada cuando Catch-Up está disponible y lanza la acción integrada **Memory Catch-Up**.
  </Step>
  <Step title="Dejar correr la revisión">
    Alter inicia la Alter Action de confianza **Memory Catch-Up** y empieza a revisar chats y reuniones de inmediato.
  </Step>
</Steps>

Catch-Up solo aparece cuando el chat está editable, inactivo y no está ejecutando otra acción ni tiene contexto adjunto.

Si Memory estaba desactivada, Catch-Up activa **Use Memory** durante la ejecución para que la revisión pueda completarse.

## Qué revisa Catch-Up

### Ventana temporal

- **30 fechas naturales inclusivas** que terminan hoy en tu zona horaria local
- Ejemplo: si hoy es 16 de julio, la ventana empieza el 17 de junio

### Fuentes

| Fuente | Incluida |
|---|---|
| Chats personales | Sí |
| Transcripciones personales de reuniones | Sí |
| Chats del workspace actual | Sí, cuando hay un workspace activo |
| Reuniones del workspace actual | Sí, cuando hay un workspace activo |
| Otros workspaces | No |

Catch-Up pagina de forma exhaustiva por chats y reuniones dentro de esa ventana. No se detiene tras la primera página de resultados.

### Qué guarda

Catch-Up busca elementos duraderos y de alta confianza, como:

- Preferencias estables
- Objetivos activos
- Decisiones claras
- Hechos útiles
- Cambios recientes significativos

Omite secretos, credenciales, datos personales sensibles, recordatorios, logística de corta vida, fragmentos en bruto y conjeturas de baja confianza.

Cada elemento guardado es un hecho conciso e independiente con procedencia desde el alcance correspondiente.

## Qué esperar durante la ejecución

Al principio, Alter te dice con claridad que revisará los últimos 30 días, comparará con la Memory guardada y solo conservará detalles realmente nuevos o actualizados.

Durante la ejecución, Alter:

1. Lee los chats dentro de la ventana de fechas
2. Lee las reuniones dentro de la ventana de fechas
3. Compara los candidatos con la Memory guardada existente
4. **Remember** hechos nuevos o **replace** hechos desactualizados cuando la evidencia es clara

Catch-Up **no**:

- Te pide aprobar cada guardado individual
- Elimina ni olvida memories existentes
- Revisa workspaces distintos del activo
- Amplía la ventana de 30 días

Cuando termina, recibes un resumen estructurado con recuentos y viñetas de los hechos añadidos o actualizados, además de una explicación breve de cómo funciona Memory y algunas preguntas de ejemplo para probar después.

## Después de Catch-Up

<CardGroup cols={2}>
  <Card title="Verificar en Settings" icon="slider" href="/es/how-to/manage-memory">
    Abre Settings → Memory para revisar lo que se guardó.
  </Card>
  <Card title="Preguntar con naturalidad" icon="message" href="/es/workflows/memory">
    Prueba "What are my current goals?" o "What did we decide about onboarding?"
  </Card>
</CardGroup>

Siguientes pasos recomendados:

1. Olvida en **Settings → Memory** cualquier elemento que sea incorrecto o ya no importe
2. Activa **Ask before saving** si quieres un control más estricto sobre los guardados automáticos futuros
3. Enlaza Memory a acciones personalizadas que deban reutilizar hechos guardados o buscar en el historial

## Catch-Up frente a la Memory diaria

Usa ambos. Catch-Up sirve para **poblar** Memory desde el historial. La Memory diaria sirve para **mantenerla** al día mientras trabajas.

| | Memory diaria | Memory Catch-Up |
|---|---|---|
| Disparador | Cada respuesta completada de Ask Anything o uso explícito de la herramienta Memory | Lo inicias desde un chat nuevo del Hub |
| Alcance del historial | Turno actual o consultas explícitas de recall | Últimos 30 días fijos de chats y reuniones |
| Aprobaciones | Depende de la fuente y de Settings | La acción de confianza guarda sin aprobación por elemento |
| Eliminaciones | Puedes olvidar elementos | No puede olvidar durante Catch-Up |
| Mejor para | Aprendizaje continuo cuando Memory ya tiene contexto | Arranque, refresco o rellenar huecos recientes |

## Notas de privacidad

Catch-Up lee chats y transcripciones locales que ya están almacenados en tu Mac. Los resultados guardados siguen siendo entradas locales de Memory.

La revisión en sí usa tu modelo generativo configurado para comparar y redactar hechos concisos. Trátalo como cualquier otra Alter Action que llama a un modelo.

Consulta también [Datos locales y privacidad](/es/references/local-data-and-privacy).
