AppSense lee datos directamente de las aplicaciones macOS para que Alter pueda trabajar con más de lo visible en pantalla.

El modo Seguir mantiene su contexto sincronizado mientras sigue trabajando, para que las respuestas de seguimiento sigan fundamentadas.

## Alter Actions - Flujos de trabajo

Las acciones le permiten guardar y reutilizar flujos de prompts de alto valor con controles de modelo y herramientas. **Mis acciones** combina una biblioteca con búsqueda, controles en línea de modelo/programación/atajo, un **chat del editor** para cambios en lenguaje natural y **documentos de acción** para edición campo a campo.

Use estas guías enfocadas:

- [Crear acciones reutilizables](/es/getting-started/actions-basics)
- [Alter Actions — Mis acciones y chat del editor](/es/workflows/alter-actions)

## Split Panel

Split Panel divide el Hub en dos paneles de conversación para investigar en uno y escribir en el otro. El puente de contexto — conversaciones, archivos, fragmentos y adjuntos — fluye entre paneles sin copiar y pegar.

Use esta guía enfocada:

- [Split Panel](/es/getting-started/split-panel)

## Compartir conversaciones en la web

Publique un chat del Hub como **enlace público de solo lectura** en alterhq.com para que otros lean el hilo completo en un navegador — sin instalar Alter. Copie la URL, **Actualice** cuando cambie la discusión o **Elimine** para despublicar.

Requiere inicio de sesión. No disponible para discusiones de reunión **Live Notepad** o **Meeting Scribe**. Separado de **Guardar conversación como Markdown** (**⌘⇧S**) local y de [Compartir trazas](/es/workflows/share-task-traces) para cargas de soporte.

Use esta guía enfocada:

- [Compartir conversaciones en la web](/es/workflows/share-conversations)

## Coding tools

Delegue trabajo de implementación a **ChatGPT**, **Cursor**, **OpenCode** o **Claude Code** desde la misma conversación de Alter. Alter ejecuta la sesión localmente, muestra el progreso en tarjetas de tarea y devuelve el resultado cuando termina el turno.

La forma más rápida de empezar es un **agente de coding del Marketplace** — descárguelo de [alterhq.com/marketplace](https://alterhq.com/marketplace) y ejecútelo una vez; Alter habilita la herramienta de coding vinculada en el primer uso.

Use esta guía enfocada:

- [Coding tools](/es/workflows/coding-tools)

## Búsqueda, filtros y Thinking effort

**Buscar y filtrar** — Encuentre texto dentro de una conversación abierta (**⌘F**), busque todo el historial del Hub (**⇧⌘F**), filtre la barra lateral por tipo de conversación, workspace, acción o etiqueta, y salte hilos largos del Hub con el índice de turnos.

**Thinking effort** — En modelos compatibles, elija **Low**, **Balanced** o **Max** desde el selector de modelo o el Editor de acciones. Alter recuerda la elección por modelo y preserva el contexto de razonamiento entre turnos de seguimiento.

Use estas guías enfocadas:

- [Tipos de ventana — Buscar y filtrar conversaciones](/es/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [Elegir su modelo generativo — Thinking effort](/es/how-to/choose-generative-model#thinking-effort)

## Memory

Memory guarda hechos concisos entre chats, workspaces y reuniones, y luego recuerda los más relevantes en nuevas conversaciones.

**¿Nuevo en Memory?** Empiece con [Memory Catch-Up](/es/workflows/memory-catch-up). En un chat nuevo del Hub, elija **Dar ventaja a Memory** para revisar los últimos 30 días de chats y reuniones e iniciar Memory de una pasada — mucho más rápido que esperar al aprendizaje cotidiano.

Use estas guías enfocadas:

- [Memory Catch-Up](/es/workflows/memory-catch-up) — primer paso recomendado para alimentar Memory desde el historial
- [Memory](/es/workflows/memory) — recuperación, aprendizaje y herramienta Memory
- [Gestionar Memory](/es/how-to/manage-memory) — revisar, olvidar y ajustar ajustes
