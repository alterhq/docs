Use esta herramienta para interacciones UI concretas tras identificar objetivos con Get Active App Context.

<Tip>
  Para trabajo UI en varios pasos, prefiera el agente [**Computer Use**](/apps-tools/computer-use) (`computer_use_task`), que llama `perform` y [`perform_sequence`](/apps-tools/computer-use-agent-tools) automáticamente.
</Tip>

## Acciones compatibles

- `click`: Clic en elemento (predeterminado).
- `fill`: Texto en campo identificado por `elementID`.
- `type`: Pulsaciones sin `elementID` (p. ej. Calculadora).
- `shortcut`: Atajos de teclado (p. ej. `cmd+c`).

## Entradas

- `action` (opcional): `click`, `fill`, `type`, or `shortcut` (predeterminado `click`).
- `elementID` (obligatorio para `click` and `fill`): ID de elemento de Get Active App Context.
- `text` (obligatorio para `fill` and `type`): Valor o pulsaciones.
- `shortcut` (obligatorio para `shortcut`): Cadena de atajo.
- `windowID` (opcional): Ventana específica (`pid/title`).

## Notas

- Los elementID expiran con cambios de UI.
- Use el mismo `windowID` en pasos de fondo.
