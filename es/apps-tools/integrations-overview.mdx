Alter se conecta a su Mac de dos formas:

- **Mac Apps (herramientas locales)** — Integraciones propias con Mail, Calendar, Messages, Notes, Reminders, Contacts, Maps, DEVONthink, Computer Use y **Coding** (ChatGPT, Cursor, OpenCode, Claude Code). Se ejecutan en su Mac con permisos del sistema; no requieren claves API para las apps integradas.
- **Gateways** — Bots de Discord y Telegram para chatear con Alter desde esas plataformas mientras Alter se ejecuta en su Mac. Configure en **Configuración → Integraciones → Gateways**.
- **Integraciones externas** — Servidores MCP, skills y conectores en la nube (Slack, Notion, GitHub, APIs de búsqueda web, etc.) configurados en **Tools Manager**.

## Elegir el tipo de integración correcto

- Use **Mac Apps** cuando el flujo permanezca en su Mac (bandeja de entrada, calendario, iMessage, automatización de pantalla).
- Use **Gateways** cuando quiera hablar con Alter desde **Discord** o **Telegram** sin abrir el Hub.
- Use **integraciones externas** cuando los datos o acciones estén en otro servicio o en la web abierta.

## Coding tools {#coding-tools}

La categoría **Coding** en **Tools Manager → Local Tools** conecta Alter con agentes de coding locales que ya ejecuta en su Mac:

- **ChatGPT** — tareas persistentes a través de la app de escritorio ChatGPT (Codex)
- **Cursor** — sesiones a través de Cursor Agent CLI
- **OpenCode** — sesiones CLI y de terminal, incluido trabajo iniciado fuera de Alter
- **Claude** — sesiones Claude Code CLI

**Recomendado:** instale un agente especializado en el [Alter Marketplace](https://alterhq.com/marketplace) — el [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent) en vivo está disponible; agentes Cursor, Claude y OpenCode próximamente. En la primera ejecución, Alter habilita automáticamente la herramienta de coding necesaria.

Alter inicia estas sesiones en segundo plano desde el Hub o una action y **devuelve los resultados a la misma conversación**. Las coding tools usan un perfil de permisos restringido mapeado desde el workspace — no exigen **Full Access** de Alter para carpetas de proyecto autorizadas.

  </Step>
  <Step title="Active solo lo necesario">

## Integraciones externas

Las integraciones externas conectan Alter con Slack, Notion, GitHub y APIs de investigación mediante **Tools Manager → Remote MCP Servers** o skills instaladas.

- Úselas cuando su flujo abarque varios sistemas fuera de las apps integradas de macOS.
- Active solo los servicios necesarios para la tarea actual.
- Los flujos de Mac Apps (Mail, Calendar, Messages) **no** requieren conectores externos — vea la sección **Mac Apps** en esta pestaña.
