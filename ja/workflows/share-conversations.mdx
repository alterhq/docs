title: "Web で会話を共有"
description: "Hub チャットを alterhq.com 上の公開読み取り専用リンクとして公開し、URL をコピー、変更時に更新、または共有を削除"
---

**会話の共有**（beta111+）は Hub チャットを**公開読み取り専用 Web ページ**として公開し、同僚、友人、協力者がブラウザでディスカッション全体を読めるようにします — Alter のインストールは不要です。

これは以下とは別です：

- **[会話を Markdown として保存](/references/shortcuts#hub--quickhub-shared)**（**⌘⇧S**）— Mac 上に**ローカル** `.md` ファイルを保存
- **[トレースを共有](/ja/workflows/share-task-traces#share-trace)** — **タスク サブエージェント** スレッドを Alter サポートにデバッグ用アップロード

## Web 共有を使う場面

| 目的 | 使う操作 |
|------|-----|
| チームが任意のブラウザで開けるリンクを送る | Hub から**共有** |
| スレッド変更後に最新メッセージを公開 | **共有**サブメニューの**更新** |
| Mac 上にプライベートなオフラインコピーを保持 | **会話を Markdown として保存**（**⌘⇧S**） |

## 要件

- Alter に**サインイン**している必要があります。ログアウトしていると、共有はサインインエラーで失敗します。
- 会話は通常の **Hub チャット**である必要があります。**Live Notepad** や **Meeting Scribe** アクションから始まった**ミーティング ディスカッション**は Web 共有できません。
- ディスカッションは保存済みである必要があります — 未保存の一時チャットには共有コントロールがありません。

## 公開される内容

Alter は次を含むパッケージをアップロードします：

- **会話タイトル**と**完全なメッセージ スレッド**（ユーザー、アシスタント、外部メッセージ）
- **メッセージに添付されたコンテキスト** — ファイル、画像、テキスト選択、アプリ コンテキスト、Mac 上でまだ利用可能な参照資料
- サイズ制限内に収まる**添付ファイル**

受信者はその内容の**読み取り専用 Web ビュー**を見ます。チャットを続けたり、共有内容を編集したりはできません。

<Warning>
  共有は**公開リンク**を作成します。URL を知っている人はディスカッションとコンテキストを閲覧できる可能性があります。公開前に機密性の高いプロンプト、ファイルパス、添付を確認してください。
</Warning>

### サイズ制限

Alter はパッケージ構築時にアップロード制限を適用します：

| 制限 | 値 |
|-------|-------|
| 単一添付 | 50 MB |
| パッケージ合計 | 200 MB |
| 添付数 | 100 ファイル |

大きすぎる、または欠落した添付は、共有全体をブロックせず、公開ビューで**利用不可**と表示される場合があります。

## 会話を共有

<Steps>
  <Step title="チャットを開く">
    **Hub** で会話を開きます（サイドバー、タブ、または QuickHub → **Hub で開く**）。
  </Step>
  <Step title="共有を選ぶ">
    以下のいずれかから **共有** を選びます。
  </Step>
  <Step title="確認">
    確認メッセージ — *ディスカッションと関連するコンテキストを含む公開リンクを作成します。リンクを知っている人は、この内容を閲覧できる可能性があります。* — を読み、**共有** をクリックします。
  </Step>
  <Step title="コピーして送信">
    成功すると Alter は **ディスカッションを共有しました** を表示し、公開 URL をクリップボードにコピーします。**リンクを開く** でブラウザプレビュー、**完了** でシートを閉じます。
  </Step>
</Steps>

アップロード中、ダイアログは **ディスカッションを共有しています…** を表示し、完了までプライマリボタンを無効にします。

## 共有の場所

### Hub サイドバー

Hub 履歴リストで会話を右クリック：

- **共有** — 新しい公開リンクを作成
- **共有**サブメニュー（既に共有済み）：
  - **リンクをコピー**
  - **更新**
  - **削除**

### 会話タブ メニュー

タブ アクションメニュー（会話タブの ⋯）から同じ **共有** 項目またはサブメニュー。

### コマンド パレット

会話タブがアクティブな状態で Hub コマンド パレット（Hub スイッチャーで既定 **⌘K**）を開き、検索：

| コマンド | 操作 |
|---------|--------|
| **会話を共有** | 公開して新しいリンクをコピー |
| **共有リンクをコピー** | 既存の公開 URL をコピー |
| **共有した会話を更新** | 最新メッセージとコンテキストを再公開 |
| **共有した会話を削除** | リンクの公開を解除 |

QuickHub は、アクティブ タブが保存済み会話のとき、スイッチャー経由で同じ共有コマンドを提供します。

## 既存の共有を管理

初回公開成功後、Alter はその会話のリンクを Mac 上に記憶します。

### リンクをコピー

サイドバーまたはタブ サブメニューの **リンクをコピー**、またはパレットの **共有リンクをコピー**。再アップロードなしで URL をコピーします。

### 更新

スレッドが変わり閲覧者に最新版を見せたいとき、**更新**（サブメニュー）または **共有した会話を更新**（パレット）を選びます。

**更新は即座に再公開** — Alter は確認ダイアログをスキップし、現在の会話状態をアップロードしてリンクを再コピーします。

### 削除

**削除**（サブメニュー）または **共有した会話を削除**（パレット）を選び、**共有を解除しますか？** — *公開されたディスカッションの公開が解除されます。* — を確認します。

削除後、公開 URL は機能しなくなります。Alter は Mac 上のその会話の保存リンクをクリアします。

## 公開リンク形式とホスティング

- リンクは **alterhq.com** で提供されます（例：`https://alterhq.com/s/...`）。
- Alter はコピー前に、返された URL が信頼できる Alter フロントエンド ホストを使うことを検証します。
- API は共有の**有効期限**タイムスタンプを返す場合があります。リンクは**取り消し可能だが秘密ではない**ものとして扱い、信頼できる相手にのみ共有してください。

共有を削除するとディスカッションの公開が解除されます。期限切れの動作は `expiresAt` 設定時の Alter サーバー ポリシーに依存します。

## プライバシーとデータ処理

会話共有は**オプトイン**であり、Alter の local-first 履歴**とは別**です：

| トピック | 動作 |
|-------|----------|
| 既定のチャット保存 | Mac に残る — [ローカル データとプライバシー](/ja/references/local-data-and-privacy) を参照 |
| Web 共有 | ディスカッション パッケージを Alter サーバーに明示的にアップロード |
| 閲覧できる人 | 公開 URL を持つ任何人（Alter アカウント不要） |
| 公開に必要なアカウント | Alter にサインイン必須 — 公開はアカウントに紐づく |
| ローカル リンク記憶 | Alter は会話ごとの最後の共有 URL をアプリ設定に保存し、コピー / 更新 / 削除 メニューを提供 |

パスワード、金融データ、機密文書、非公開ミーティング録画を含む会話は、Web 上で見せる意図がない限り共有しないでください。

元のチャットで使ったクラウド モデル プロバイダーは共有とは別 — 共有は会話スナップショットの内容のみアップロードし、ローカル DB 全体ではありません。

## トラブルシューティング

**メニューに共有がない**

- ミーティング **Live Notepad** と **Meeting Scribe** チャットは Web 共有不可
- 先に会話を保存 — 未保存の一時チャットには共有コントロールなし
- 別の共有ダイアログやアップロード進行中は待つ

**ログイン エラーで共有失敗**

- **設定 → プロフィール** またはアカウント メニューでサインインして再試行

**パッケージが大きすぎて共有失敗**

- コンテキストから大きな添付を削除するか、**会話を Markdown として保存** でエクスポートして自分の経路で共有
- 制限：ファイル 50 MB、合計 200 MB、添付 100 件

**リンクをコピーしても何も起きない**

- サーバーに共有がなくなった場合は **更新** で再公開
- 最初に共有した同じ Mac からコピーしていることを確認（リンク記憶はローカル）

**公開リンクではなくサポート バンドルが必要**

- [トレースを共有](/ja/workflows/share-task-traces#share-trace) で Alter サポートへタスク デバッグをアップロード
