<Info>
  **Alter Actions** は、特定のタスク向けに特化したアシスタントを作成できるカスタマイズ可能な AI ワークフローです。AI 指示、音声トリガー、ツール、条件付き実行を組み合わせて、Mac 上のあらゆる作業を自動化できます。
</Info>

## Alter Action とは

**Alter Action** は、次の要素を組み合わせた高度な自動化です。

- **AI 指示** — AI の振る舞いを定義するシステムプロンプト
- **トリガー** — 音声コマンド、ホットキー、条件付き実行
- **コンテキスト** — 選択テキスト、ファイル、アクティブなアプリケーションへのアクセス
- **ツール** — Mac および 2000 以上の外部サービスとの連携設定
- **出力** — 結果の表示方法（マークダウン、コード、インライン挿入）

Alter Action は、特定のタスク向けにカスタマイズされた「特化型 AI アシスタント」と考えてください。

## マイアクションを開く

Alter では、アクションは **ツールとアクション** 内で管理されます。**マイアクション** セクションには、検索可能なアクション一覧、インライン操作、そしてアクションの作成・変更を代行してくれる **エディタチャット** が統合されています。

### 方法 1: キーボードショートカット（最速）

**⌘⇧E**（Command + Shift + E）を押します。Alter は **ツールとアクション** を **マイアクション** 画面で直接開きます。

### 方法 2: ウィンドウメニュー

1. 任意の Alter ウィンドウ（Hub、QuickHub、または ツールとアクション）を開く
2. **ウィンドウ → マイアクション** を選択

### 方法 3: ツールとアクションのサイドバー

1. **⌘⇧T**（Command + Shift + T）を押して **ツールとアクション** を開く
2. サイドバーで **マイアクション** を選択

サイドバーのバッジには、現在有効になっているアクション数が表示されます。

<Tip>
  **⌘⇧E** はアクション管理に直接ジャンプします。**⌘⇧T** は Marketplace、有効な Tools、クイックアクション、Skills、リモート MCP を含む ツールとアクション ウィンドウ全体を開きます。
</Tip>

<Note>
  **マイアクション** とアクションドキュメントにはサインインが必要です。ログアウトしている場合、Alter はエディタの代わりにログインオーバーレイを表示します。
</Note>

## マイアクションのレイアウト

**マイアクション** を選択すると、ウィンドウには 3 つの作業エリアがあります。

| エリア | 役割 |
|------|------|
| **左** | ツールとアクション ナビゲーション（Marketplace、ローカルツール、クイックアクション、Skills、リモート MCP、**マイアクション**） |
| **中央** | アクション一覧 — フォルダ、検索、フィルター、行ごとの操作 |
| **右** | **エディタチャット** — 平易な言葉で変更内容を伝えると Alter が適用 |

![メニューバー](/images/tools/menu-bar-action-editor.webp)

初回訪問時、何も選択されていなければ、エディタチャットは **Manage my Actions** モードで開き、新しいアクションの説明やライブラリ全体の変更内容を伝えられます。

### アクション一覧

アクションは **フォルダ**（カテゴリ）ごとにグループ化されます。次の操作ができます。

- **検索** — **⌘F** でアクション名とインデックス済みリソースプロパティ（ツール、ゲートウェイ、クイックアクション、類似のリンク済みリソース）を検索
- **フィルター** — フィルターアイコンで、バックグラウンドジョブ、スケジュール、警告、変更済みアクション、公開済みリスト、無効アクション、特定フォルダで絞り込み
- フォルダの **折りたたみ・展開**、フォルダの **名前変更**、**アクションのドラッグ** によるフォルダ間移動
- **複数アクションの選択** による一括エクスポート、移動、有効化/無効化、削除
- ツールバーから **フォルダを作成** し、ドラッグ＆ドロップまたは行のコンテキストメニューからアクションを追加

各行には、一目でわかるクイックステータスが表示されます。

- **アイコンと名前** — 名前をダブルクリック（または 1 行選択して **Return**）でアクションドキュメントを開く
- 音声フレーズが設定されている場合の **音声トリガー** インジケーター
- 組み込みアクションをカスタマイズした場合の **Modified by you** バッジ
- **バックグラウンドジョブ** インジケーター
- リストから取得したアクションの **Marketplace** インジケーター
- 診断で構成問題が見つかった場合の **警告** インジケーター

### インライン行操作

ドキュメント全体を開かなくても、各行の右側に 3 つの操作が表示されます。

| 操作 | 役割 |
|------|------|
| **Model** | **Default** を選ぶか、このアクション用にモデルと thinking effort を固定 |
| **Schedule** | スケジュールの表示、追加、編集、削除 |
| **Shortcut** | グローバルキーボードショートカットの記録または変更 |

ショートカットが未設定の行では、ホバーするとショートカット操作が表示されます。

### 行のコンテキストメニュー

1 つ以上のアクションを右クリックして、**実行**、**編集**、**名前変更**、**キーボードショートカット** の設定、フォルダへの **移動**、**有効化** / **無効化**、**複製**、**エクスポート**、**Marketplace に公開**、**削除** / **リセット** ができます。

**編集** は、アクションドキュメントを別ウィンドウで開き、フィールド単位で編集します。

## エディタチャット

右カラムは、アクション管理専用のチャットです。Alter の高速モデルと固定の管理ツールセットを使うため、各タブをクリックしなくても、やりたいことを説明するだけで済みます。

### チャットでできること

Alter に次のような依頼ができます。

- 説明から **新しいアクションを作成**（「毎朝 9 時に実行するデイリースタンドアップ要約アクションを作って」）
- 選択中アクションのプロンプト、パラメーター、表示設定、モデル、ツール、スケジュール、ゲートウェイを **編集**
- グローバルまたは 1 つのアクション単位でツールを **有効化またはスコープ設定**
- **クイックアクション** の構成 — Alter が webhook、AppleScript/JXA、ショートカットなどの設定フォームをレビュー付きで開く
- **Connected Applications** と **MCP サーバー** をネイティブ承認シート経由で **接続**
- Skills の **インストールまたは有効化**
- 1 つのアクションの **警告を診断**、またはライブラリ全体を **スキャン**
- 名前、説明、リンク済みリソースで **アクションを検索**（「Discord ゲートウェイを使っているアクションはどれ？」）
- 自動化用の **コールバック URL をコピー**

アクションを選択すると、Alter は最初のメッセージと一緒に現在の設定スナップショットを送るため、アシスタントはファイルを再読み込みせずにすぐ編集できます。

各アクションは **独自のチャット履歴** を保持します。行を切り替えると会話も切り替わり、入力欄の下書きはアクションごとに保持されます。チャットヘッダーのゴミ箱ボタンで会話をクリアできます。

<Tip>
  チャットと手動編集を組み合わせましょう。チャットにプロンプトの下書きやツール接続を依頼し、その後 **アクションドキュメント** を開いて文言、パラメーター、ゲートウェイのトグルを自分で微調整できます。
</Tip>

### 承認と機密設定

破壊的または特権的な変更は、ネイティブシートまたはアラートで確認が必要です — たとえばアクションの削除、組み込み上書きのリセット、OAuth アプリの接続、MCP サーバーの構成、ツールのインストール、クイックアクションの webhook やスクリプトの保存など。

削除が失敗した場合、Alter は **依存関係ブロッカー** を説明します（たとえばクイックアクションや workspace からまだリンクされているアクション）と、先に解除すべき項目を伝えます。

### 提案用のプロフィールコンテキスト

エディタチャットは、カスタマイズされた提案を生成する際に **プロフィール** 情報を含めます — たとえば作業スタイルに合ったツールや文言を推奨する場合など。そのワークフローでプロフィールコンテキストを送りたくない場合は、アクションドキュメントの **General → プロフィールを含める** でアクションごとにオフにできます。

## アクションドキュメント

精密な制御が必要な場合は **アクションドキュメント** を開きます — 左にセクションタブ、右にフィールドがある専用ウィンドウです。プロンプトを直接編集したり、パラメーターを調整したり、すべてのトグルを確認したいときに使います。

**ドキュメントを開く方法:**

- 一覧でアクション名をダブルクリック
- 1 つのアクションを選択して **Return**
- 右クリック → **編集**
- 別の Alter ウィンドウから、現在のアクションに **Edit in Action Editor** が表示されている場合はそれを使用

ドキュメントウィンドウのタイトルにはアクション名が表示されます。カスタマイズした組み込みアクションは編集可能な上書きとして表示されます。完全に独立したコピーが必要な場合は、先に複製してください。

### 1. General

基本メタデータ、利用可否、実行コンテキストを構成します。

![General タブ](/images/tools/action-editor-01-general.webp)

**フィールド:**

- **Enabled** — アクションのオン/オフ
- **Mode** — Hub 入力エリアで選択可能なモードとして表示
- **プロフィールを含める** — AI コンテキストにユーザープロフィール情報を含める
- **Save to History** — このアクションの会話を History に保存し、後から再開・検索できるようにする
- **Name**、**Description**、**Category**、**Icon**
- **Workspace** — このアクション実行時に常に workspace をコンテキストに追加
- **Global Keyboard Shortcut** — Mac 上のどこからでもこのアクションを起動
- **Voice Triggers** — ディクテーション中にこのアクションを実行するフレーズ

**表示オプション**（**表示するタイミング** でも要約）:

- **Show only when running** — 選択したアプリが実行中の場合のみアクションを表示
- **Show only when active** — 選択したアプリがフォーカスされている場合のみアクションを表示
- **Workspace context** — このアクションを表示する workspace を制限

<Note>
  各アクションには一意の UUID が自動的に付与されます。組み込みアクションは、複製するか上書きを保存するまで読み取り専用です。
</Note>

### 2. システムプロンプト

モデル向けの AI 指示とパラメーターを定義します。

![システムプロンプト タブ](/images/tools/action-editor-02-systemprompt.webp)

**システムプロンプト** — AI の振る舞いと専門性を記述するコア AI 指示。

**例:**
```
# IDENTITY AND PURPOSE
You are an expert software engineer who explains code clearly
and accessibly to developers of all skill levels.

# STEPS
1. Analyze the provided code
2. Identify its purpose and key components
3. Explain each section in simple terms

# OUTPUT INSTRUCTIONS
- Use markdown formatting
- Include code examples where helpful
- Keep language clear and non-technical
```

**Parameters** — 実行前にユーザーがカスタマイズできる入力フィールドを定義（テキスト入力、ドロップダウン、ブール値、数値など）。

### 3. ユーザープロンプト

AI に送られるユーザー向けプロンプトのテンプレート。

![ユーザープロンプト タブ](/images/tools/action-editor-03-userprompt.webp)

**コンテキスト変数の使用:**

`{{ }}` で変数を囲み、動的コンテンツを挿入します。

```
Please explain this code:

{{ textSelection }}

Explanation detail: {{ detailLevel }};
```

**利用可能なコンテキスト変数:**
- `{{ textSelection }}` — 現在選択中のテキスト
- `{{ filePath }}` — 選択中ファイルのパス
- `{{ clipboard }}` — クリップボードの内容
- システムプロンプトで定義したカスタムパラメーター

### 4. 表示するタイミング

このアクションがいつ・どこに表示されるかを制御します。

![表示するタイミング タブ](/images/tools/action-editor-04-whentoshow.webp)

**表示条件:**

- **Installed Applications** — 特定のアプリ（VSCode、Xcode、Safari など）でのみアクションを表示
- **Application is running** — アプリが実行中である必要がある
- **Application has focus** — アプリが前面にある場合のみ動作
- **Web browser tab contains** — 特定ドメインを閲覧中にアクションを表示
- **Has content** — コンテキストが利用可能な場合のみアクションを表示

### 5. Automation

実行動作、スケジュール、バックグラウンド処理を構成します。

![Automation タブ](/images/tools/action-editor-05-automation.webp)

**フィールド:**

- **Background Job** — UI を表示せずバックグラウンドでアクションを実行
- **Background markdown rendering** — バックグラウンドモードで貼り付け時にマークダウンを HTML にレンダリング
- **Send a system notification** — バックグラウンドジョブ完了後に通知
- **Schedules** — 特定時刻にアクションを実行（例: 「毎週月曜 9:00」）
- **Quick Action** — 最初のアシスタント応答後にリンク済みクイックアクションを自動実行

スケジュールとクイックアクションを組み合わせてアクションチェーンを構築できます: 最初のアクション → 出力 → 次のステップが自動実行。

### 6. Tools

このアクションで利用可能なツールをスコープ設定します。

![Tools タブ](/images/tools/action-editor-06-tools.webp)

**ツール構成:**

- **Disable Tools** — オフの場合、選択したツールのみ利用可能。オンの場合、ツールアクセスが制限される
- ツールアクセスが有効で選択が空の場合: グローバルで有効化されたすべてのツールが利用可能
- 構成済みの場合: 選択したツールのみ利用可能

**何でも聞く のデフォルト（beta100+）:** 組み込み **何でも聞く** アクションは **Flow**、**Computer Use**、**Ask User** を最初から有効にしています。より狭いツールセットが必要な場合はカスタマイズまたは複製してください。

**Memory:** アクションが保存済みの事実を読み取る、または過去のチャットや会議を検索する必要がある場合は **Memory** ツールをリンクします。Memory はすべてのアクションでデフォルト有効ではありません。詳細は [Memory](/ja/workflows/memory) と [Manage Memory](/ja/how-to/manage-memory) を参照してください。

組み込み **Memory Catch-Up** アクションには Memory がすでにリンクされています。直近 30 日間のチャットと会議から Memory をブートストラップする Alter の推奨方法です — Memory を初めて有効にするとき、または最近の履歴をバックフィルしたいときに使ってください。詳細は [Memory Catch-Up](/ja/workflows/memory-catch-up) を参照してください。

**コーディングツール（post-beta106）:** 最速の方法は [Marketplace コーディングエージェント](/ja/workflows/coding-tools#get-started-from-the-marketplace-recommended) です — **ツールとアクション → Marketplace → Browse** からダウンロード（例: ライブ [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent)）し、1 回実行するだけで、Alter が初回使用時に必要なコーディング連携を有効化します。代替として、**ローカルツール → Coding** で **ChatGPT**、**Cursor**、**OpenCode**、**Claude** を **ツールとアクション** で先に接続し、各アクションが使えるプロバイダーをスコープ設定 — たとえばリリースアクションでは **Cursor** のみ有効化。コーディングセッションは非同期で実行され、結果は元の会話に返ります。詳細は [Coding tools](/ja/workflows/coding-tools) を参照してください。

**ツールをスコープする理由:**
- AI の判断負荷を減らす（関連ツールに集中）
- アクション実行を高速化
- セキュリティ向上（アクションがアクセスできる範囲を制限）

**エディタチャット** に依頼して、このタブを開かずにツールを追加・削除することもできます。

### 7. Model

AI モデル、thinking effort、創造性レベルを選択します。

![Model タブ](/images/tools/action-editor-07-model.webp)

**フィールド:**

- **Model** — **Current**、**Favorites**、**Other models** にグループ化された検索可能ピッカー。空のままにするとユーザーのデフォルトモデル設定を使用し、特定モデルを固定することも可能。
  - 各行にコンテキスト長、ビジョン対応、お気に入りを表示
  - モデルが対応している場合、**Thinking effort**（**Low**、**Balanced**、**Max**）をインラインで調整

- **Temperature** — 創造性と精度のバランス
  - **0.0** — 決定論的（一貫性、予測可能）
  - **0.5** — バランス（デフォルト）
  - **1.0** — 創造的（予測不能、探索的）

Alter は Hub、QuickHub、マイアクション、アクションドキュメント全体で **モデルごとの** thinking effort を記憶します。

<Tip>
  マイアクションで **⌘F** を使ってアクションを検索。フィルターアイコンでバックグラウンドジョブ、スケジュール、警告、変更済みアクション、公開済みリスト、**Folders** で絞り込み。フォルダーフィルターには **All** と **None** ショートカットがあります。
</Tip>

### 8. Gateways

このアクションを利用できるゲートウェイ接続を正確に選択します。構成済みの Buzz、Discord、Telegram ゲートウェイごとにトグルがあり、同じプラットフォーム上の 2 つのアカウントでも異なるアクセス設定が可能です。

<Info>
  **Buzz gateway（internal）** — Buzz は Alter 内部ビルドの開発チーム向けにのみ表示されます。詳細は [Buzz gateway (internal)](/ja/apps-tools/gateways-buzz) を参照してください。
</Info>

**Availability** — ゲートウェイトグル:

| 設定 | 効果 |
|------|------|
| すべてのトグルがオフ | ローカルのみ（Hub、QuickHub など） |
| 1 つのゲートウェイがオン | その名前付きゲートウェイ接続からのみ利用可能 |
| 複数のゲートウェイがオン | プラットフォームをまたいで、指定した接続からのみ利用可能 |
| すべてのトグルがオン | 現在構成されているすべてのゲートウェイから利用可能 |

バンドル **何でも聞く** アクションは最初、互換性のあるすべてのゲートウェイに表示されます。カスタムアクションは、1 つ以上のゲートウェイトグルを有効にするまでローカルのみです。トグルを変更するとゲートウェイ接続の明示的リストが保存されるため、後から追加されたゲートウェイは自動的にそのアクションを継承しません。

Gateways では、**パラメーターなしアクション**（入力フィールドなし）は **Choose action** から選ぶと即座に実行されます。**パラメーター付きアクション** はユーザーの次のメッセージを待ちます。

**スケジュール済みゲートウェイ配信** — アクションがスケジュールで実行される場合、**Start scheduled conversations on a gateway** を有効にし、有効な **Discord**、**Telegram**、または **Buzz** *(internal)* ゲートウェイを選び、**Destination**（チャンネル、チャット、または Buzz ストリーム）を指定します。Alter はローカル実行だけでなく、アクションの最初の応答をそこに投稿します。Buzz ゲートウェイは **Settings → Integrations → Gateways** で **Default scheduled destination** も設定できます。

セットアップ、チャットコマンド、スケジュール配信、ゲートウェイ設定は [Gateways](/ja/apps-tools/gateways) を参照してください。

### 診断と警告

マイアクションとアクションドキュメントの両方で、設定ミスがある場合 **警告** が表示されます — クイックアクションの欠落、無効なアイコン、壊れたゲートウェイ参照、workspace の問題など。

- 行またはセクションの警告バッジをクリックして詳細と推奨修正を確認
- 一覧を **Warnings** でフィルターし、要対応アクションを監査
- エディタチャットに「このアクションの警告を修正して」や「すべてのアクションの問題をスキャンして」と依頼

警告は保存済み構成のみを記述し、過去の実行での振る舞いを保証するものではありません。

## x-callback-url 連携

特殊 URL を使って **任意のアプリケーション** から Alter アクションを起動できます。強力なクロスアプリ自動化ワークフローが可能になります。

### x-callback-url とは

x-callback-url は、アプリ間通信プロトコルで、フォーマット済み URL 経由でアプリ同士のアクションを起動できます。

- **Inbound** — 他アプリ（Shortcuts、Notes、Safari など）から Alter アクションを起動
- **Outbound** — Alter 内で他アプリ（Bear、OmniFocus、Drafts など）を開くリンクを作成

### アクションのコールバック URL を取得

<Steps>
  <Step title="マイアクションを開く">
    **⌘⇧E** を押す
  </Step>
  <Step title="選択または依頼">
    一覧でアクションを選択するか、エディタチャットにコールバック URL を依頼
  </Step>
  <Step title="アクションドキュメントを開く">
    アクションをダブルクリック（またはコンテキストメニューから **編集**）
  </Step>
  <Step title="General に移動">
    **General** セクションに移動
  </Step>
  <Step title="URL をコピー">
    **URL Callback** から `alter://` URL をコピーするか、エディタチャットが返した URL を貼り付け
  </Step>
</Steps>

**形式:**
```
alter://action/{action-id}?input=VALUE&param2=VALUE
```

### 他アプリから Alter アクションを起動

**例 1: Safari から Web 検索**
```
alter://action/ask-web?input=What+is+Alter+MacOS
```

**例 2: 入力付き Code Explainer**
```
alter://action/explain-code?input=const+hello+%3D+%28%29+%3D%3E+%7B%7D
```

**例 3: Apple Shortcuts での使用**
1. 新しい Shortcut を作成
2. 「Open URL」アクションを追加
3. `alter://` URL を貼り付け
4. Shortcut を実行してアクションを起動

## トラブルシューティング

<AccordionGroup>
  <Accordion icon="circle-exclamation" title="アクションがメニューに表示されない">
    - アクションドキュメントの **表示するタイミング** 設定を確認
    - アプリが実行中/アクティブか確認（設定している場合）
    - アクションが **有効** になっているか確認
  </Accordion>

  <Accordion icon="triangle-exclamation" title="アクションは動くが出力が不十分">
    - **システムプロンプト** を見直す — より具体的に
    - **Temperature** を調整（精度重視なら下げ、創造性重視なら上げる）
    - **ユーザープロンプト** を確認 — 変数が正しいか
  </Accordion>

  <Accordion icon="microphone" title="音声トリガーが動作しない">
    - Settings でホットキーが構成されているか確認
    - マイクの権限を確認
    - まず手動トリガーでテスト
  </Accordion>

  <Accordion icon="lock" title="アクションでツールが利用できない">
    - アクションドキュメント → **Tools** セクションを開く
    - ツールが無効化されていないか、正しいツールが選択されているか確認
    - **ツールとアクション → 有効な Tools** でツールが有効化されているか確認
    - 不明な場合はエディタチャットにツールアクセスの確認を依頼
  </Accordion>

  <Accordion icon="stethoscope" title="アクションに警告が表示される">
    - 警告バッジをクリックして詳細を確認
    - リンクされたセクション（Tools、Gateways、Quick Action など）を開いて参照を修正
    - エディタチャットに選択中アクションの診断と修復を依頼
  </Accordion>

  <Accordion icon="trash" title="アクションを削除できない">
    - 依存関係メッセージを読む — 別のクイックアクション、アクション、または workspace がまだ参照している可能性
    - それらのリンクを先に解除し、コンテキストメニューまたはエディタチャットから削除を再試行
  </Accordion>
</AccordionGroup>
