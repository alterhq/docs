## アプリとの対話

### AppSense - Mac を理解する

AppSense は macOS アプリから直接データを読み取り、Alter が画面上に見えるもの以外も扱えるようにします。

- [現在のアプリとフォロー モードを使用する](/ja/getting-started/use-current-app-and-follow-mode)

フォロー モードは作業を続けながらコンテキストを同期し、フォローアップの回答が根拠を保つようにします。

この焦点を絞ったガイドを使用してください：

- [現在のアプリとフォロー モードを使用する](/ja/getting-started/use-current-app-and-follow-mode)

ワークスペースはより大きなコンテキストをインデックス化して準備し、より大きなファイル セットで反復可能なタスクを実行できます。

この焦点を絞ったガイドを使用してください：

## Alter Actions - ワークフロー

アクションでは、モデルとツール制御付きで価値の高いプロンプト ワークフローを保存して再利用できます。**マイアクション** には、検索可能なライブラリ、インラインのモデル/スケジュール/ショートカット操作、自然言語での変更用 **エディタチャット**、フィールドごとの編集用 **アクションドキュメント** が統合されています。

これらの焦点を絞ったガイドを使用してください：

- [再利用可能なアクションを作成する](/ja/getting-started/actions-basics)
- [Alter Actions — マイアクションとエディタチャット](/ja/workflows/alter-actions)

## Gateways

Gateways は Alter を **Discord** と **Telegram** に接続し、Alter が Mac 上に留まっている間にそれらのチャット アプリからアクションを実行できます。

これらの焦点を絞ったガイドを使用してください：

- [Gateways overview](/apps-tools/gateways)
- [Discord をセットアップ](/apps-tools/gateways-discord)
- [Telegram をセットアップ](/apps-tools/gateways-telegram)

## Split Panel

Split Panel は Hub を 2 つの会話ペインに分割し、一方で調査しながらもう一方で執筆できます。コンテキスト ブリッジ — 会話、ファイル、スニペット、添付 — はコピー&ペーストなしでペイン間を流れます。

この焦点を絞ったガイドを使用してください：

- [Split Panel](/ja/getting-started/split-panel)

## Web で会話を共有

Hub チャットを alterhq.com 上の **公開読み取り専用リンク** として公開し、Alter のインストールなしでブラウザでスレッド全体を読めます。URL をコピーし、議論が変わったら **更新**、非公開にするには **削除** します。

サインインが必要です。ミーティングの **Live Notepad** または **Meeting Scribe** ディスカッションでは利用できません。ローカルの **会話を Markdown として保存**（**⌘⇧S**）およびサポート アップロード用の [トレースを共有](/ja/workflows/share-task-traces) とは別です。

この焦点を絞ったガイドを使用してください：

- [Web で会話を共有](/ja/workflows/share-conversations)

## Coding tools

同じ Alter 会話から **ChatGPT**、**Cursor**、**OpenCode**、**Claude Code** に実装作業を委任します。Alter はローカルでセッションを実行し、タスク カードで進捗を表示し、ターン完了時に結果を返します。

最速の開始方法は **Marketplace coding エージェント** — [alterhq.com/marketplace](https://alterhq.com/marketplace) からダウンロードして一度実行；初回使用時に Alter がリンクされた coding ツールを有効にします。

この焦点を絞ったガイドを使用してください：

- [Coding tools](/ja/workflows/coding-tools)

## 検索、フィルター、Thinking effort

**検索とフィルター** — 開いている会話内のテキストを検索（**⌘F**）、Hub 履歴全体を検索（**⇧⌘F**）、サイドバーを会話タイプ、ワークスペース、アクション、タグでフィルターし、長い Hub スレッドをターン インデックスで移動。

**Thinking effort** — サポートされるモデルでは、モデル スイッチャーまたはアクションエディタから **Low**、**Balanced**、**Max** を選択。Alter はモデルごとに選択を記憶し、フォローアップ ターン間で推論コンテキストを保持します。

これらの焦点を絞ったガイドを使用してください：

- [ウィンドウ タイプ — 会話の検索とフィルター](/ja/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [生成モデルを選ぶ — Thinking effort](/ja/how-to/choose-generative-model#thinking-effort)

## Memory

Memory はチャット、ワークスペース、ミーティング間で簡潔な事実を保存し、新しい会話で最も関連性の高いものを思い出します。

**Memory は初めて？** [Memory Catch-Up](/ja/workflows/memory-catch-up) から始めてください。新しい Hub チャットで **Give Memory a head start** を選び、過去 30 日間のチャットとミーティングをレビューして Memory を一括で初期化 — 日常の学習を待つよりはるかに速いです。

これらの焦点を絞ったガイドを使用してください：

- [Memory Catch-Up](/ja/workflows/memory-catch-up) — 履歴から Memory を供給する推奨の第一歩
- [Memory](/ja/workflows/memory) — リコール、学習、Memory ツール
- [Memory を管理](/ja/how-to/manage-memory) — レビュー、忘却、設定の調整
