## ゴール

明確なトラブルシューティング手順により、統合を安全に接続および管理します。

## ステップ

1. Alter 設定を開き、統合またはTools Managerに移動します。
2. 一度に 1 つの統合を接続し、すぐにテストします。
3. 必要な権限とアカウントのスコープを確認します。
4. 簡単なテスト プロンプトを作成して、予想される動作を確認します。
5. 失敗した場合は、プロバイダー認証を確認して再試行してください。

## 多数の Tools の管理

多くのツールを有効にすると、コンテキスト ウィンドウの使用量が増加し、パフォーマンスに影響します。ほとんどのワークフローでは、リクエストごとに適切なツールを自動的に選択する **Flow** - Alter のツール オーケストレーターを使用します。

<Card title="Tool オーケストレーションには Flow を使用する" icon="wand-magic-sparkles" href="/workflows/use-flow-orchestration">
  Flow は、リクエストを適切な統合に自動的にルーティングする単一のツールとして機能することで、コンテキストの使用量を削減します。
</Card>

すべてのツールをすべてのリクエストにロードするのではなく、Flow:
- リクエストを分析し、適切なツールを選択します
- 複数のツールにわたるマルチステップのオーケストレーションを処理します
- コンテキスト ウィンドウの使用量を減らし、パフォーマンスを向上させます。

**Local Tools > Alter** の Tool マネージャーで Flow を有効にします。

## Coding tools

**Tools Manager → Local Tools → Coding** には 4 つのローカルコーディング統合が一覧表示されます：

| プロバイダー | 接続する場合 |
|-------------|--------------|
| **ChatGPT** | ChatGPT デスクトップアプリでエージェント型コーディングを使う |
| **Cursor** | Cursor Agent CLI（`agent`）をインストール済み |
| **OpenCode** | OpenCode CLI（ターミナルセッション含む）を使う |
| **Claude** | ターミナルで Claude Code（`claude`）を使う |

**最速の方法:** **[Marketplace → Browse](https://alterhq.com/marketplace)** から専用エージェントをインストール — 例：公開中の [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent)。初回実行時、Alter がリンクされたコーディングツールの有効化を促します。[Coding tools — Marketplace オンボーディング](/ja/workflows/coding-tools#get-started-from-the-marketplace-recommended) を参照。

必要なプロバイダーのみ接続してください。各プロバイダーは現在の Action で有効な場合、Alter のモデルに run、list、control、settings ツールを公開します。

## トラブルシューティング

- プロバイダ接続を再認証します。
- ローカル/ネットワークの権限を確認します。
- 統合固有の制限とクォータを確認します。
