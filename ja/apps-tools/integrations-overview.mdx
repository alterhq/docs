Alter は 2 つの方法で Mac に接続します：

- **Mac Apps（ローカルツール）** — Mail、Calendar、Messages、Notes、Reminders、Contacts、Maps、DEVONthink、Computer Use のファーストパーティ連携。Mac 上でシステム権限で動作；組み込みアプリにサードパーティ API キーは不要。
- **Gateways** — Alter が Mac 上で動作している間、Discord と Telegram から Alter とチャットするボット。**設定 → Integrations → Gateways** で設定。
- **外部連携** — **Tools Manager** で設定する MCP サーバー、スキル、クラウドコネクタ（Slack、Notion、GitHub、Web 検索 API など）。

## 適切な連携タイプを選ぶ

- ワークフローが Mac 上に留まる場合（受信トレイ、カレンダー、iMessage、画面自動化）は **Mac Apps** を使用。
- Hub を開かずに **Discord** や **Telegram** から Alter と話したい場合は **Gateways**。
- データやアクションが別サービスやオープン Web にある場合は **外部連携** を使用。

## Coding tools {#coding-tools}

**Tools Manager → Local Tools** の **Coding** カテゴリは、Mac 上ですでに実行しているローカルコーディングエージェントに Alter を接続します：

- **ChatGPT** — ChatGPT デスクトップアプリ（Codex）経由の永続タスク
- **Cursor** — Cursor Agent CLI 経由のセッション
- **OpenCode** — CLI およびターミナルセッション（Alter 外で開始した作業を含む）
- **Claude** — Claude Code CLI セッション

**推奨:** [Alter Marketplace](https://alterhq.com/marketplace) から専用エージェントをインストール — 公開中の [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent) が利用可能；Cursor、Claude、OpenCode エージェントは近日公開。初回実行時、Alter が必要なコーディングツールを自動有効化します。

Alter は Hub または Action からこれらのセッションをバックグラウンドで開始し、**同じ会話に結果を返します**。Coding tools は Workspace からマップされた制約付き権限プロファイルを使用 — 承認済みプロジェクトフォルダに Alter **Full Access** は不要です。

### ローカルツールを有効化

<Steps>
  <Step title="Tools Manager を開く">
    Alter で三点メニュー → **Tools Manager**。
  </Step>
  <Step title="必要なものだけ有効化">
    実行中のワークフローに関連するローカルツールをオン。
  </Step>
  <Step title="1 つのプロンプトでテスト">
    小さなプロンプトで権限と動作を確認。
  </Step>
</Steps>

## 外部連携

外部連携は **Tools Manager → Remote MCP Servers** またはインストール済みスキル経由で Slack、Notion、GitHub、調査 API に接続。

- macOS 組み込み以外の複数システムにまたがるワークフローで使用。
- 現在のタスクに必要なサービスのみ有効化。
- Mac Apps ワークフロー（Mail、Calendar、Messages）は外部コネクタ **不要** — このタブの **Mac Apps** を参照。
