O modo Seguir mantém o contexto sincronizado enquanto continua a trabalhar, para que as respostas de seguimento permaneçam fundamentadas.

## Alter Actions - Fluxos de trabalho

As acções permitem guardar e reutilizar fluxos de prompts de alto valor com controlos de modelo e ferramentas. **Minhas ações** combina uma biblioteca pesquisável, controlos inline de modelo/agendamento/atalho, um **chat do editor** para alterações em linguagem natural e **documentos de ação** para edição campo a campo.

Use estes guias focados:

- [Criar acções reutilizáveis](/pt/getting-started/actions-basics)
- [Alter Actions — Minhas ações e chat do editor](/pt/workflows/alter-actions)

## Split Panel

O Split Panel divide o Hub em dois painéis de conversação para pesquisar num e escrever no outro. A ponte de contexto — conversas, ficheiros, excertos e anexos — flui entre painéis sem copiar e colar.

Use este guia focado:

- [Split Panel](/pt/getting-started/split-panel)

## Partilhar conversas na web

Publique um chat do Hub como **ligação pública só de leitura** em alterhq.com para outros lerem o thread completo num browser — sem instalar o Alter. Copie o URL, **Actualize** quando a discussão mudar ou **Remova** para despublicar.

Requer início de sessão. Indisponível para discussões de reunião **Live Notepad** ou **Meeting Scribe**. Separado de **Guardar conversa como Markdown** (**⌘⇧S**) local e de [Partilhar traces](/pt/workflows/share-task-traces) para uploads de suporte.

Use este guia focado:

- [Partilhar conversas na web](/pt/workflows/share-conversations)

## Coding tools

Delegue trabalho de implementação a **ChatGPT**, **Cursor**, **OpenCode** ou **Claude Code** a partir da mesma conversa Alter. O Alter executa a sessão localmente, mostra progresso em cartões de tarefa e entrega o resultado quando o turno termina.

A forma mais rápida de começar é um **agente de coding do Marketplace** — descarregue de [alterhq.com/marketplace](https://alterhq.com/marketplace) e execute uma vez; o Alter activa a ferramenta de coding ligada na primeira utilização.

Use este guia focado:

- [Coding tools](/pt/workflows/coding-tools)

## Pesquisa, filtros e Thinking effort

**Pesquisar e filtrar** — Encontre texto numa conversa aberta (**⌘F**), pesquise todo o histórico do Hub (**⇧⌘F**), filtre a barra lateral por tipo de conversa, workspace, acção ou tag, e navegue threads longos do Hub com o índice de turnos.

**Thinking effort** — Em modelos suportados, escolha **Low**, **Balanced** ou **Max** no selector de modelo ou Editor de acções. O Alter memoriza a escolha por modelo e preserva contexto de raciocínio entre turnos de seguimento.

Use estes guias focados:

- [Tipos de janela — Pesquisar e filtrar conversas](/pt/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [Escolher o seu modelo generativo — Thinking effort](/pt/how-to/choose-generative-model#thinking-effort)

## Memory

O Memory guarda factos concisos entre chats, workspaces e reuniões, e depois recorda os mais relevantes em novas conversas.

**Novo no Memory?** Comece com [Memory Catch-Up](/pt/workflows/memory-catch-up). Numa conversa nova do Hub, escolha **Dar vantagem ao Memory** para rever os últimos 30 dias de chats e reuniões e iniciar o Memory numa passagem — muito mais rápido do que esperar pelo aprendizagem quotidiana.

Use estes guias focados:

- [Memory Catch-Up](/pt/workflows/memory-catch-up) — primeiro passo recomendado para alimentar Memory a partir do histórico
- [Memory](/pt/workflows/memory) — recall, aprendizagem e ferramenta Memory
- [Gerir Memory](/pt/how-to/manage-memory) — rever, esquecer e ajustar definições
