O Alter conecta-se ao seu Mac de duas formas:

- **Mac Apps (ferramentas locais)** — Integrações first-party com Mail, Calendar, Messages, Notes, Reminders, Contacts, Maps, DEVONthink e Computer Use. Executam no Mac com permissões do sistema; sem chaves API de terceiros para apps integradas.
- **Gateways** — Bots Discord e Telegram para conversar com o Alter a partir dessas plataformas enquanto o Alter corre no Mac. Configure em **Definições → Integrations → Gateways**.
- **Integrações externas** — Servidores MCP, skills e conectores na nuvem (Slack, Notion, GitHub, APIs de pesquisa web, etc.) configurados no **Tools Manager**.

## Escolher o tipo de integração certo

- Use **Mac Apps** quando o fluxo permanece no Mac (triagem de e-mail, calendário, iMessage, automação de tela).
- Use **Gateways** quando quiser falar com o Alter a partir do **Discord** ou **Telegram** sem abrir o Hub.
- Use **integrações externas** quando dados ou ações estão em outro serviço ou na web aberta.

### Abrir 

<Steps>
  <Step title="Abrir Tools Manager">
    No Alter, abra o menu de três pontos e selecione **Tools Manager**.
  </Step>
  <Step title="Ative só o necessário">
    Ative as ferramentas locais relevantes para o fluxo.
  </Step>
  <Step title="Testar com um prompt">
    Execute um prompt pequeno para confirmar permissões e comportamento.
  </Step>
</Steps>

## Integrações externas

Integrações externas conectam o Alter a Slack, Notion, GitHub e APIs de pesquisa via **Tools Manager → Remote MCP Servers** ou skills instaladas.

- Use quando o fluxo abrange vários sistemas fora dos apps integrados do macOS.
- Ative apenas os serviços necessários para a tarefa atual.
- Fluxos Mac Apps (Mail, Calendar, Messages) **não** exigem conectores externos — veja **Mac Apps** nesta aba.
