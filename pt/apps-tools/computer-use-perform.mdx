Use esta ferramenta para interações UI concretas após identificar alvos com Get Active App Context.

<Tip>
  Para trabalho UI em várias etapas, prefira o agente [**Computer Use**](/apps-tools/computer-use) (`computer_use_task`), que chama `perform` e [`perform_sequence`](/apps-tools/computer-use-agent-tools) automaticamente.
</Tip>

## Ações suportadas

- `click`: Clique no elemento (padrão).
- `fill`: Texto em campo com `elementID`.
- `type`: Digitação sem `elementID` (ex.: Calculadora).
- `shortcut`: Atalhos (ex.: `cmd+c`).

## Entradas

- `action` (opcional): `click`, `fill`, `type`, or `shortcut` (padrão `click`).
- `elementID` (obrigatório para `click` and `fill`): ID do elemento do Get Active App Context.
- `text` (obrigatório para `fill` and `type`): Valor ou teclas.
- `shortcut` (obrigatório para `shortcut`): String de atalho.
- `windowID` (opcional): Janela específica (`pid/title`).

## Notas

- elementIDs expiram com mudanças de UI.
- Use o mesmo `windowID` em etapas de fundo.
