<Info>
  **Memory Catch-Up** é a forma mais rápida de começar a alimentar a Memory. Revê a tua actividade recente no Alter, compara-a com o que já está guardado e adiciona ou actualiza apenas factos duradouros que valem a pena manter, sem pedir aprovação para cada um.
</Info>

## Porque o Catch-Up é o melhor primeiro passo

A Memory do dia a dia aprende gradualmente, com no máximo um facto candidato por resposta concluída de Ask Anything. Isso funciona bem quando a Memory já tem contexto. Se estás a começar do zero, é lento.

**Memory Catch-Up** resolve esse problema de arranque. Numa única execução:

- Analisa os **últimos 30 dias de calendário** de chats pessoais e transcrições de reuniões
- Inclui o **workspace actual** quando houver um activo
- Compara candidatos com a Memory guardada antes de escrever o que quer que seja
- Guarda automaticamente factos de alta confiança como uma Alter Action de confiança

Pensa no Catch-Up como a primeira vez que enches o caderno. A Memory do dia a dia trata depois de o manter actualizado.

## Quando o deves usar

Executa o Memory Catch-Up quando:

- Acabaste de activar **Use Memory** e queres dar vantagem à Memory
- **Settings → Memory** está vazio, mas já tens semanas de actividade no Alter
- Voltas depois de uma pausa e queres captar objectivos, decisões e preferências recentes
- Mudaste para um workspace novo e queres contexto de projecto a partir de trabalho recente
- Caso contrário, irias colar o mesmo enquadramento em cada novo chat

O Catch-Up é um preenchimento pontual dos **últimos 30 dias de calendário**, não um indexador contínuo em segundo plano. Podes executá-lo outra vez mais tarde se quiseres uma nova actualização de 30 dias.

## Como iniciar o Catch-Up

<Steps>
  <Step title="Abrir um chat novo do Hub">
    Abre o Hub e inicia um **novo separador de conversa**. O Catch-Up é oferecido num chat vazio, não a meio de uma thread.
  </Step>
  <Step title="Escolher a sugestão">
    Selecciona **Dar vantagem à Memory** nas sugestões de boas-vindas. Surge como um card recomendado quando o Catch-Up está disponível e lança a acção integrada **Memory Catch-Up**.
  </Step>
  <Step title="Deixar a revisão correr">
    O Alter lança a Alter Action de confiança **Memory Catch-Up** e começa logo a rever chats e reuniões.
  </Step>
</Steps>

O Catch-Up só aparece quando o chat pode ser escrito, está inactivo e não está já a executar outra acção ou contexto anexado.

Se a Memory estava desactivada, o Catch-Up activa **Use Memory** durante a execução para que a revisão possa terminar.

## O que o Catch-Up revê

### Janela temporal

- **30 datas de calendário inclusivas** a terminar hoje no teu fuso horário local
- Exemplo: se hoje for 16 de Julho, a janela começa em 17 de Junho

### Fontes

| Fonte | Incluída |
|---|---|
| Chats pessoais | Sim |
| Transcrições pessoais de reuniões | Sim |
| Chats do workspace actual | Sim, quando houver um workspace activo |
| Reuniões do workspace actual | Sim, quando houver um workspace activo |
| Outros workspaces | Não |

O Catch-Up pagina exaustivamente por chats e reuniões dentro dessa janela. Não pára após a primeira página de resultados.

### O que guarda

O Catch-Up procura itens duradouros e de alta confiança, como:

- Preferências estáveis
- Objectivos activos
- Decisões claras
- Factos úteis
- Alterações recentes significativas

Ignora segredos, credenciais, dados pessoais sensíveis, lembretes, logística de curta duração, excertos brutos e suposições de baixa confiança.

Cada item guardado é um facto conciso e autónomo com proveniência do âmbito correspondente.

## O que esperar durante a execução

No início, o Alter explica em linguagem clara que vai rever os últimos 30 dias, comparar com a Memory guardada e guardar apenas detalhes realmente novos ou actualizados.

Durante a execução, o Alter:

1. Lê chats dentro da janela de datas
2. Lê reuniões dentro da janela de datas
3. Compara candidatos com a Memory guardada existente
4. **Remember** factos novos ou **replace** factos desactualizados quando a evidência é clara

O Catch-Up **não**:

- Pede a tua aprovação para cada gravação individual
- Apaga nem esquece memories existentes
- Revê workspaces para além do activo
- Alarga a janela de 30 dias

Quando termina, recebes um resumo estruturado com contagens e pontos sobre factos adicionados ou actualizados, mais uma explicação curta de como a Memory funciona e algumas perguntas de exemplo para experimentares a seguir.

Próximos passos recomendados:

1. Esquece em **Settings → Memory** tudo o que estiver errado ou já não for relevante
2. Liga **Ask before saving** se quiseres controlo mais apertado sobre gravações automáticas futuras
3. Liga a Memory a acções personalizadas que devam reutilizar factos guardados ou pesquisar histórico

## Catch-Up vs. Memory do dia a dia

Usa os dois. O Catch-Up serve para **preencher** a Memory a partir do histórico. A Memory do dia a dia serve para **mantê-la** actualizada enquanto trabalhas.

| | Memory do dia a dia | Memory Catch-Up |
|---|---|---|
| Disparo | Cada resposta concluída de Ask Anything ou uso explícito da ferramenta Memory | Inicias a partir de um chat novo do Hub |
| Âmbito do histórico | Turno actual ou pedidos explícitos de recall | Últimos 30 dias fixos de chats e reuniões |
| Aprovações | Depende da fonte e das Settings | A acção de confiança guarda sem aprovação por item |
| Eliminações | Podes esquecer itens | Não pode esquecer durante o Catch-Up |
| Melhor para | Aprendizagem contínua quando a Memory já tem contexto | Arranque, actualização ou preenchimento de lacunas recentes |

## Notas de privacidade

O Catch-Up lê chats e transcrições locais já armazenados no teu Mac. Os resultados guardados continuam a ser entradas locais de Memory.

A revisão em si usa o teu modelo generativo configurado para comparar e formular factos concisos. Trata-a como qualquer outra Alter Action que chama um modelo.
