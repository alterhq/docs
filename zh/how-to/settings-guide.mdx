## 目标

了解如何自定义 Alter 以符合你的偏好、管理账户、配置 AI 模型，以及设置权限以实现最佳生产力。

## 步骤

### 1. 访问设置

打开设置有以下三种方式：

**选项 1：菜单栏**
点击菜单栏中的 Alter 图标，然后从下拉菜单中选择 **Settings...**。

**选项 2：键盘快捷键**
按 **⌘ ,（Command + 逗号）** 直接打开 Settings。

**选项 3：Notch 菜单**
点击 Alter Notch 中的三点菜单图标 (⋮)，然后选择 **Settings**。

![菜单栏访问](/images/settings/Alter-Menu_Bar-Menu.webp)

### 常规设置 {#general}

在 **General** 选项卡中，你可以配置 QuickHub Mode、Edge Bar、选区辅助、默认模型参数以及通知规则。

#### 快速访问

- **Selection Button** — 选中文本时在鼠标光标旁显示快速访问按钮
- **QuickHub Mode** — 所有对话使用 QuickHub 而非 Notch（新用户默认 **开启**）。关闭后，全局快捷键标签显示 **Open notch** 而非 **Open QuickHub**。参见 [QuickHub Mode](/getting-started/quickhub-mode)。

#### Edge Bar

Edge Bar 设置位于 QuickHub Mode 下方，**QuickHub Mode 关闭时会被禁用**。

- **Left edge** / **Right edge** — 独立启用屏幕边缘启动器（默认：右侧开启，左侧关闭）
- **All monitor edges** — 在每个显示器上使用已选定的左/右边缘，包括显示器之间的边缘。关闭时，多显示器设置下仅外缘可用
- **Opening distance** — 滑块从 **0%**（贴边）到 **100%**（默认距离），步进 25%

该部分页脚说明唤出行为与多显示器规则。完整指南：[Edge Bar](/getting-started/edge-bar)。

打开 QuickHub（默认 **⌘⇧Space**）、Hub（**⌘⇧H**）和新聊天（**⌥Space**）的全局快捷键在 **Settings → Shortcuts → Global** 中配置，不在此选项卡。

**LLM Settings**
- **Max Tokens**：设置 AI 回复的最大长度
- **Temperature**：控制回复的创造性与变化程度（0.0 = 确定性，1.0 = 创造性；默认：0.70）

**Notifications**
- **Summarize YouTube video**：访问 YouTube 视频时自动创建摘要
- **Record to transcript**：自动将录音转写至笔记（更多选项请前往 Notes 设置）

![常规设置](/images/settings/Alter-Settings_01_General-Beta71.webp)

### 2. 语音设置 {#voice}

**Voice** 选项卡控制 Alter 如何处理和响应音频：

**General Configuration**

- **Audio behavior during dictation**：控制听写时系统音频的处理方式。选项包括 ducking（降低音量）或完全静音，以尽量减少干扰
- **Keep awake during meeting**：会议录制期间防止 Mac 休眠或进入省电模式，确保转写不中断
- **Play chime when starting recording**：开始听写或会议录制时播放提示音

**Language & Vocabulary**
- **Dictation language**：选择语音输入的首选语言
- **Personal Dictionary**：添加自定义术语和转写替换
- **Manage Replacements**：编辑经常被误识别的词

**Voice Processor**
选择语音处理模型：
- **Apple**：内置，针对隐私优化
- **Local / Local Plus**：在 Mac 上使用已下载的 Whisper 或 Parakeet 模型运行
- **Cloud**：通过 **Soniox V5** 在线转写（beta96+）；符合条件时会议转写准确度最佳

![语音设置](/images/settings/Alter-Settings_02_Voice-Beta71.webp)

#### 语音设置 - 键盘快捷键

配置键盘快捷键，以便从任意位置快速使用语音功能：

- **Keyboard Shortcut**：开始/停止语音输入并说出命令。自定义激活键以实现免提操作。按住说话以提示，点按进行听写。
- **Meeting Shortcut**：快速访问会议专用语音命令
- **Live Captions**：说话时启用实时转写叠加层
- **Live Notepad**：打开 Live Notepad 面板，将语音输入直接捕获到笔记中

这些快捷键可让你在不切换窗口或离开键盘的情况下激活 Alter 的语音功能。

![语音快捷键](/images/settings/Alter-Settings_02a_Voice-Shortcuts-Beta71.webp)

#### 语音设置 - 自动化

配置会议和录制的自动化：
- **Meeting apps**：选择要监控会议的应用
- **Auto record meetings**：检测到会议时自动开始录制
- **Find speakers names (experimental)**：仅 Cloud 的说话人识别；启用日历和 Contacts 匹配（beta93+）
- **Calendars for speaker matching**：选择用于匹配日程和推荐与会者姓名的 Apple 日历
- **Contacts for speaker matching**：将与会者邮箱解析为显示名称
- **Keep dictation in pasteboard**：在剪贴板中保留语音输入

**Cloud processor：** 选择 **Cloud** 作为语音处理器时，会议和听写转写使用 **Soniox V5** 引擎（beta96+）以提高准确度。需要登录且具备 cloud dictation 资格。

![语音自动化](/images/settings/Alter-Settings_02b_Voice-Automation-Beta71.webp)

#### 语音设置 - 词典

建立个人词典以实现准确转写：
- 添加 Alter 经常误识别的词或短语
- 为你的领域或工作流创建自定义术语

![语音词典](/images/settings/Alter-Settings_02c_Voice-Dictionary-Beta71.webp)

#### 语音设置 - 替换

设置常见转写错误的词替换：
- 将经常听错的词映射为正确词
- 示例："Alter" → "Alter"（若被误听为 "Altar"）

![语音替换](/images/settings/Alter-Settings_02d_Voice-Replacements-Beta71.webp)

#### 语音设置 - 本地模型

使用 Local 处理器时，可从本地语音处理模型中选择：

**Why Local Processing?**
- **Complete privacy**：所有音频处理均在 Mac 上完成——不会向云服务发送任何数据
- **Zero data sharing**：录音、转写和说话人识别完全保留在你的设备上
- **GDPR compliant**：遵循 privacy by design 原则
- **Always available**：离线可用，不依赖互联网

**Local** - 基础本地模型选项
- 用于语音转文本的 Whisper 模型
- 多种模型尺寸（Tiny、Base、Small、Medium、Large 等）
- 根据准确度与性能的权衡进行选择

**Whisper Models**

OpenAI Whisper 支持 50 多种语言，覆盖全球：
- **Major languages**：英语、西班牙语、法语、德语、葡萄牙语、俄语、意大利语、日语、韩语、中文
- **European languages**：荷兰语、波兰语、罗马尼亚语、瑞典语、乌克兰语、希腊语、捷克语、匈牙利语、斯洛伐克语、土耳其语、丹麦语、挪威语、芬兰语
- **Other languages**：阿拉伯语、希伯来语、印地语、越南语、泰语、印尼语、他加禄语、孟加拉语、泰米尔语、马拉地语、卡纳达语等

**Features:**
- 自动生成词级时间戳
- 说话人识别（谁说了什么）
- 针对 Mac 性能优化至 626MB
- 最适合全球语言覆盖与准确度

Whisper 在广泛使用的语言上表现优异，但对于训练数据较少的不常见语言，准确度可能有所差异。

![语音 - 本地模型](/images/settings/Alter-Settings_02e_Voice-Local-Beta71.webp)

**Local Plus** - 付费功能

包含 Whisper 和 Parakeet 模型，并支持自动语言检测：

**Whisper Models**（99 种语言）
- 与 Local 选项相同的广泛语言支持
- 针对不同语言环境优化准确度

**Parakeet Models**（25 种欧洲语言）
- NVIDIA 快速、轻量的语音转文本引擎
- **Mac 上会议转写比 Whisper 快 10 倍**
- 从音频自动检测语言
- 支持保加利亚语、克罗地亚语、捷克语、丹麦语、荷兰语、英语、爱沙尼亚语、芬兰语、法语、德语、希腊语、匈牙利语、意大利语、拉脱维亚语、立陶宛语、马耳他语等 9 种以上欧洲语言

**Features:**
- 说话人分离（识别不同说话人）
- 针对 Mac 性能优化至 494MB
- 适合实时会议录制
- 最适合欧洲语言工作负载

**Choose your model:**
- **Parakeet**：处理更快、资源占用更低，适合会议（25 种欧洲语言）
- **Whisper**：更广的语言覆盖，最高准确度（50+ 种全球语言）

两种模型均提供词级时间戳、说话人识别和自动语言检测——全部在 Mac 上本地处理。

![语音 - Local Plus 模型](/images/settings/Alter-Settings_02f_Voice-Local_Plus-Beta71.webp)

### 9. Computer use 设置 {#computer-use}

**Computer use** 选项卡配置 Alter 的 UI 自动化代理如何驱动应用、浏览器，以及 **2.0.0-beta100** 引入的浮动实时预览。

打开 **Settings**（⌘,），在侧边栏选择 **Computer use**——它位于 API 部分，带有 cursor-rays 图标，与 **API keys** 和 **Router** 并列。该选项卡分为三个与应用 UI 完全一致的部分：**Browser**、**Preview** 和 **Blocked apps**。

#### Browser

为 Computer Use 配置独立浏览器，使代理驱动的页面与日常浏览分离。

**Agent browser** — *Computer use 代理驱动的浏览器*

- **macOS default** — Computer Use 内的 `open_urls` 使用系统默认浏览器（开箱即用行为）
- **Dedicated browser** — 选择已安装的浏览器（Chrome、Safari、Arc 等）。Computer Use 运行期间，代理打开的页面仅进入此浏览器。你自己打开的链接，以及 Computer Use **之外**的 `open_urls`，仍使用 macOS 默认浏览器。

这样你可以在主浏览器中保持敏感站点登录状态，而代理使用隔离的配置文件。

**Clean up when finished**

- 启用后，Alter 会在**最后一次** Computer Use 会话结束后关闭代理打开的标签页
- 对于无法关闭单个标签页的浏览器（例如 Firefox），改为**退出**代理浏览器——但**仅当代理启动它时**，不会退出你已打开的浏览器
- 需要专用 **Agent browser**（选择 **macOS default** 时禁用）

#### Preview

浮动预览以画中画形式实时显示 Computer Use 正在控制的窗口。

**Show preview automatically** — *Computer use 任务开始时显示浮动预览*

- 开启（默认）：任务开始时打开预览
- 关闭：任务仍在后台运行；可随时通过运行中任务的 Tool Inspector 中的 **Watch preview** 打开预览

**Preview size** — *Small 或 Large 预设，或 Custom 以保留你拖拽后的尺寸*

| Option | Width |
|--------|-------|
| **Small** | 320 pt 预设 |
| **Large** | 560 pt 预设 |
| **Custom** | 记住你拖拽预览角设置的尺寸 |

预览保持固定宽高比；可用窗口上的 **Hide** 控件隐藏预览，而不会停止运行。

#### Blocked apps

Computer Use 拒绝**打开、读取或控制**此列表中的应用。密码管理器和其他敏感应用默认被阻止：

- Keychain Access
- Bitwarden
- Passwords (macOS)
- 1Password / 1Password 7

**Add app…** — 从 `/Applications` 选择一个或多个 `.app` 包以阻止

**Restore defaults** — 将列表重置为 Alter 内置的敏感应用默认值

点击行上的减号按钮移除应用。若目标指向被阻止的应用，代理会报告阻止并停止尝试——仅在你有意让 Computer Use 控制该应用时才调整列表。

没有应用被阻止时，该部分以次要文本显示 **No apps are blocked.**。

#### 权限提醒

Computer Use 需要 **Accessibility**（读取 AX 树并发送点击）和 **Screen Recording**（用于实时预览和 `computer_use_screenshot`）。首次运行前在 **Settings → Permissions** 中授予两者。若仍有问题，打开 **Settings → Doctor** 查看汇总的权限报告。

<Tip>
  后台运行、Edge Bar 会话卡片和预览行为详见 [Background Computer Use](/apps-tools/computer-use-background)。权限问题：[Tools Not Working](/common-issues/tool-not-working) 或 **Settings → Doctor**。
</Tip>

### 10. Shortcuts 设置 {#shortcuts}

**Shortcuts** 选项卡是可搜索的编辑器，涵盖所有 Alter 键盘快捷键。打开 **Settings → Shortcuts**（位于侧边栏 **General** 部分下）。

### 11. Marketplace 设置 {#marketplace}

**Marketplace** 选项卡（位于设置侧边栏 **Account** 下）控制你的公开 Alter Marketplace 个人资料和通知偏好。此处保存的内容可能出现在 agent 列表和社区页面；仅本地的 Alter 设置不受影响。

#### Public Profile

- **Display Name** — 公开资料上显示的用户名
- **Bio** — 最多 **160 个字符**；实时计数器显示 `count/160`
- **Avatar** — 点击相机徽章选择图片；**Remove** 清除当前头像
- **Save Profile** — 上传更改（未编辑时禁用）

保存时个人资料数据会同步到 Alter 账户服务。错误以红色显示在表单下方。

#### Social Links

Marketplace 个人资料上显示的可选 URL：

- **Website**
- **GitHub**
- **Twitter / X**
- **LinkedIn**
- **Discord**
- **YouTube**

字段留空则公开隐藏该链接。值与账户个人资料一起存储。

#### Notifications

- **Comment notifications** — *当有人评论你的 agent 或回复你时收到通知。*

关闭可静音 Marketplace 评论提醒，同时保持公开资料可见。

### 12. Doctor 设置 {#doctor}

**Doctor**（位于设置侧边栏 **System** 下）对 Alter 运行健康与权限诊断。工具莫名失败、语音处理异常，或需要脱敏报告联系支持时使用。

打开该选项卡时 Doctor 会自动运行，然后显示摘要和详细部分。

#### 摘要标题

- **Alter Doctor** 标题及 **last checked** 时间
- 总体状态标签：**OK**、**Warning**、**Failed** 或 **Idle**
- 计数标签：**OK**、**Idle**、**Warn**、**Fail**

#### Refresh 与 Copy Report

- **Refresh** — 重新运行所有检查（运行时显示进度指示器）
- **Copy Report** — 将**脱敏**纯文本报告复制到剪贴板（主目录路径缩短为 `~`；JWT/类 token 字符串被替换）。按钮短暂显示 **Copied**

联系支持时，可将报告粘贴到 Discord 或邮件中；如相关，一并附上 [shared task trace](/workflows/share-task-traces)。

#### 诊断部分

**Environment**

- **macOS** — 操作系统版本字符串
- **Architecture** — `arm64` 或 `x86_64`

**Application**

- **Version** — 短版本号、构建号和配置（Debug/Release）
- **Application Support** — Alter 支持目录是否存在

**Permissions**

- **Accessibility** — 选区读取和应用控制所需。未授予时链接到 **Settings → Permissions**
- **Screen Recording** — 会议/屏幕上下文和 Computer Use 预览所需
- **Microphone** — 听写和会议音频所需
- **Automation** — AppleScript 风格自动化所需的 System Events 访问。点击 **Check Automation** 前为 **Idle**；Alter 会提示权限并刷新报告

**Voice Processor**

- **Selected processor** — 当前语音引擎（Apple、cloud、Whisper 等），链接到 **Settings → Voice**
- **Plan access** — 你的订阅是否支持所选处理器
- **Local model** / **Local model runtime**（仅 Apple Silicon + Whisper）— 下载和加载状态

**Storage**

Application Support、Alter Prompts、Caches、WebKit 和 HTTP Storage 路径的磁盘使用量。

**Database**

本地 Core Data 架构状态：最新、需要迁移或尚无存储。

**Actions**

已加载的 Alter Actions 数量（已启用、用户编写、总计）。

**Tools**

- **Activated tools** — 数量，含 **Open the Tools Manager** 快捷方式至 Active Tools 部分
- **MCP configuration** — 已连接应用和远程 MCP 服务器
- **MCP clients** — 各服务器运行时状态（running、stopped、error）

**Search**

- **Conversations** / **Transcripts** — 已索引记录数；重新索引时为 **Warning**
- **Notes** — Apple Notes 工具是否活跃

#### 部分操作

部分包含页脚按钮：

- **Open Permissions**、**Open Voice**、**Open Billing** — 跳转到相应设置选项卡
- **Open the Tools Manager** — 深链到 MCP 或 active tools 部分
- **Check Automation** — 触发 System Events 权限检查（Permissions 部分）
