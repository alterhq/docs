## Alter Actions - 工作流

操作让您保存并重复使用高价值提示工作流，并控制模型和工具。**我的操作** 结合了可搜索库、内联模型/计划/快捷键控件、用于自然语言更改的 **编辑器聊天**，以及用于逐字段编辑的 **操作文档**。

- [创建可重复使用的操作](/zh/getting-started/actions-basics)

Gateways 将 Alter 连接到 **Discord** 和 **Telegram**，以便在 Alter 留在 Mac 上时从这些聊天应用运行操作。

使用这些聚焦指南：

## Split Panel

Split Panel 将 Hub 分为两个对话窗格，以便在一个中研究并在另一个中写作。上下文桥接 — 对话、文件、片段和附件 — 在窗格之间流动，无需复制粘贴。

使用此聚焦指南：

- [Split Panel](/zh/getting-started/split-panel)

## 在 Web 上分享对话

将 Hub 聊天发布为 alterhq.com 上的 **公开只读链接**，以便他人在浏览器中阅读完整线程 — 无需安装 Alter。复制 URL，讨论变化时 **更新**，或 **移除** 以取消发布。

需要登录。不适用于会议 **Live Notepad** 或 **Meeting Scribe** 讨论。与本地 **将对话保存为 Markdown**（**⌘⇧S**）以及用于支持上传的 [分享追踪](/zh/workflows/share-task-traces) 分开。

使用此聚焦指南：

- [在 Web 上分享对话](/zh/workflows/share-conversations)

## Coding tools

从同一 Alter 对话将实现工作委托给 **ChatGPT**、**Cursor**、**OpenCode** 或 **Claude Code**。Alter 在本地运行会话，在任务卡中显示进度，并在回合完成时返回结果。

最快的开始方式是 **Marketplace coding 代理** — 从 [alterhq.com/marketplace](https://alterhq.com/marketplace) 下载并运行一次；Alter 在首次使用时启用链接的 coding 工具。

使用此聚焦指南：

- [Coding tools](/zh/workflows/coding-tools)

## 搜索、筛选器和 Thinking effort

**搜索和筛选** — 在打开的 conversation 中查找文本（**⌘F**），搜索全部 Hub 历史（**⇧⌘F**），按对话类型、工作区、操作或标签筛选侧边栏，并使用回合索引跳转长 Hub 线程。

**Thinking effort** — 在支持的模型上，从模型切换器或操作编辑器选择 **Low**、**Balanced** 或 **Max**。Alter 按模型记住选择并在后续回合中保留推理上下文。

使用这些聚焦指南：

- [窗口类型 — 搜索和筛选对话](/zh/getting-started/window-types-notch-hub-panels#search-and-filter-conversations)
- [选择生成模型 — Thinking effort](/zh/how-to/choose-generative-model#thinking-effort)

## Memory

Memory 在聊天、工作区和会议之间保存简洁事实，然后在新对话中回忆最相关的内容。

**Memory 新手？** 从 [Memory Catch-Up](/zh/workflows/memory-catch-up) 开始。在新的 Hub 聊天中，选择 **Give Memory a head start** 以回顾过去 30 天的聊天和会议并一次性填充 Memory — 比等待日常学习快得多。

使用这些聚焦指南：

- [Memory Catch-Up](/zh/workflows/memory-catch-up) — 从历史记录填充 Memory 的推荐第一步
- [Memory](/zh/workflows/memory) — 回忆、学习和 Memory 工具
- [管理 Memory](/zh/how-to/manage-memory) — 审查、遗忘和调整设置
