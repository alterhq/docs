Alter 通过两种方式连接您的 Mac：

- **Mac Apps（本地工具）** — 与 Mail、Calendar、Messages、Notes、Reminders、Contacts、Maps、DEVONthink 和 Computer Use 的第一方集成。在 Mac 上以系统权限运行；内置应用无需第三方 API 密钥。
- **外部集成** — 在 **Tools Manager** 中配置的 MCP 服务器、技能和云连接器（Slack、Notion、GitHub、网络搜索 API 等）。

## 选择正确的集成类型

- 工作流留在 Mac 上时（收件箱分类、日历更新、iMessage、屏幕自动化）使用 **Mac Apps**。
- 数据或操作位于其他服务或开放网络时使用 **外部集成**。

## Coding tools {#coding-tools}

**Tools Manager → Local Tools** 中的 **Coding** 类别将 Alter 连接到您已在 Mac 上运行的本地编程智能体：

- **ChatGPT** — 通过 ChatGPT 桌面应用（Codex）的持久任务
- **Cursor** — 通过 Cursor Agent CLI 的会话
- **OpenCode** — CLI 和 Terminal 会话，包括 Alter 外启动的工作
- **Claude** — Claude Code CLI 会话

**推荐：** 从 [Alter Marketplace](https://alterhq.com/marketplace) 安装专用智能体 — 已上线的 [ChatGPT Agent](https://alterhq.com/marketplace/chatgpt-agent) 现已可用；Cursor、Claude 和 OpenCode 智能体即将推出。首次运行时，Alter 会自动启用所需的编程工具。

Alter 从 Hub 或 Action 在后台启动这些会话，然后**将结果返回同一对话**。Coding tools 使用从 Workspace 映射的受限权限配置文件 — 对于授权的项目文件夹，它们不需要 Alter **Full Access**。

### 打开 

<Steps>
  <Step title="打开 Tools Manager">
    在 Alter 中打开三点菜单并选择 **Tools Manager**。
  </Step>
  <Step title="仅启用所需项">
    为当前工作流开启相关本地工具。
  </Step>
  <Step title="用一个提示测试">
    运行小提示以确认权限和预期行为。
  </Step>
</Steps>

## 外部集成

外部集成通过 **Tools Manager → Remote MCP Servers** 或已安装技能将 Alter 连接到 Slack、Notion、GitHub 和研究 API。

- 工作流跨越 macOS 内置应用之外的多个系统时使用。
- 仅启用当前任务所需的服务。
- Mac Apps 工作流（Mail、Calendar、Messages）**不需要**外部连接器 — 见本标签页的 **Mac Apps** 部分。
