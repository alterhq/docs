title: "共享和导出任务追踪"
description: "将任务对话导出为 Markdown、与 Alter 团队共享追踪，并从 Tool Inspector 打开子智能体聊天"
---

当 Alter 运行**产生任务的工具** — **Computer Use**、**Flow** 或其他生成子对话的智能体 — 时，父聊天会在 **Tool Inspector** 中显示工具运行。你可以**打开完整任务线程**、**导出为 Markdown** 或**共享追踪**给 Alter 团队以进行调试。

此工作流与使用 **将对话保存为 Markdown**（**⌘⇧S**）保存普通 Hub 对话不同。任务追踪捕获**子智能体**的交互，包括父消息触发的工具调用。

## 何时使用各选项

| 操作 | 使用场景 |
|--------|-------------|
| **在标签页中打开** | 想在 Alter 内阅读完整任务对话 |
| **导出聊天** | 需要本地 **.md** 文件用于记录或离线审阅 |
| **共享追踪** | 出现故障或意外行为 — 向 Alter 发送诊断信息 |
| **将对话保存为 Markdown**（**⌘⇧S**） | 想导出**父级** Hub/QuickHub 聊天，而不仅是任务子线程 |

## 在哪里找到任务操作

1. 运行产生任务的工具（例如让 Alter 执行 **Computer Use** 目标，或调用 **Flow**）
2. 在 **Hub** 或 **QuickHub** 中打开对话的 **Inspector** 面板（侧边栏 Inspector 切换）
3. 在 inspector 中选择**工具运行** — `computer_use_task`、Flow 或其他任务智能体所在行
4. 滚动到**任务对话**操作块（高亮强调背景）

会出现三个操作：

- **在标签页中打开**
- **导出聊天**
- **共享追踪**

上传共享时，按钮显示 **正在共享追踪...** 并在请求完成前禁用。

活跃的 **Computer Use** 运行中，inspector 还可能显示 **Watch preview** — 见 [后台 Computer Use](/apps-tools/computer-use-background)。

## 在标签页中打开

**在标签页中打开** 跳转到**只读任务对话** — 子智能体线程及其自己的消息、工具调用和结果。适用于：

- 父回复已总结结果，但你需要逐步详情
- 需要从子线程复制特定工具参数或结果
- 在导出前审阅较长的 **Computer Use** 运行

任务标签页在 Hub 上下文中打开。如果从 QuickHub 触发工具，需要完整 Hub 标签布局时先使用 **在 Hub 中打开**（**⌘O**）。

## 导出聊天

**导出聊天** 将任务对话保存为 **Markdown 文档**：

1. 在 Tool Inspector 中点击 **导出聊天**
2. 在保存面板中选择位置（默认：**Downloads**）
3. Alter 写入以任务标题命名的 `.md` 文件（无标题时为 **Task Chat**）
4. Finder 打开包含该文件的文件夹

导出包含任务标题和子智能体对话的格式化消息 — 与追踪共享相同的内容，但**保存在你的 Mac 本地**。

<Tip>
  要导出**父级**对话（主聊天中可见的一切，不仅是子智能体子线程），使用 **将对话保存为 Markdown** — 默认 **⌘⇧S**，**设置 → 快捷键 → Hub**。
</Tip>

## 共享追踪

**共享追踪** 将诊断包上传到 Alter API，以便团队调查 bug、权限失败或意外的智能体行为。

### 要求

- 必须**登录** Alter（有效的账户 JWT）。未登录时共享会因认证错误失败。
- 所选工具运行必须存在任务对话。

### 发送内容

- **标题** — 任务对话标题
- **Markdown** — 格式化的任务消息（与导出聊天相同）
- **工具名称** — 例如 `computer_use_task` 或 Flow 工具 ID
- **任务对话 ID** — 关联父线程和子线程的内部标识符
- **应用版本** — Alter 构建字符串，用于复现

成功时 Alter 显示 **追踪已共享** — *追踪已与 Alter 团队共享。*

失败时显示 **共享追踪失败** 及错误信息（网络、认证或服务器）。

### 隐私

追踪用于**支持和调试**，而非公开分享：

- 内容反映**任务子智能体**看到和做了什么
- **屏幕内容**、窗口标题和 Computer Use 中的文件路径可能出现在 Markdown 中
- Doctor 报告中的主目录路径在使用 **复制报告** 时会脱敏；任务导出**不会**自动脱敏

除非有意向 Alter 支持披露，否则不要共享包含密码、财务数据或机密文档的追踪。

## 将对话保存为 Markdown（父级聊天）

**将对话保存为 Markdown** — 默认 **⌘⇧S** — 通过 Hub 菜单或快捷键将**活跃的 Hub 或 QuickHub 对话**导出为 Markdown。它**不能替代**工具运行上的 **导出聊天**：

- **⌘⇧S** → 完整父线程
- **导出聊天**（inspector）→ 仅子智能体任务子线程

在 **设置 → 快捷键 → Hub** 中自定义。

## 故障排除

**Inspector 中缺少任务操作**

- 工具必须是有关联子对话的**产生任务**运行
- 等待工具启动完成

**导出聊天蜂鸣但无效果**

- 任务对话已从内存释放 — 重新运行工具，或在任务仍加载时打开父对话

**共享追踪因登录错误失败**

- 在 **设置 → 个人资料** 或账户菜单中登录，然后重试

**需要可公开分享的链接**

- **共享追踪** 上传到 Alter 支持；不会复制公开 URL。如需 Alter 外的链接，使用 **导出聊天** 并通过自己的渠道分享 `.md` 文件。
