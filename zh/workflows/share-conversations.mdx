title: "在 Web 上分享对话"
description: "将 Hub 聊天发布为 alterhq.com 上的公开只读链接，复制 URL，讨论变更时更新，或移除分享"

**对话分享**（beta111+）将 Hub 聊天发布为**公开只读网页**，供同事、朋友或协作者在浏览器中阅读完整讨论 — 无需安装 Alter。

这与以下功能不同：

- **[将对话保存为 Markdown](/references/shortcuts#hub--quickhub-shared)**（**⌘⇧S**）— 在 Mac 上保存**本地** `.md` 文件
- **[共享追踪](/zh/workflows/share-task-traces#share-trace)** — 将**任务子智能体**线程上传到 Alter 支持以进行调试

## 何时使用 Web 分享

| 目标 | 使用 |
|------|-----|
| 发送可在任何浏览器中打开的链接 | 在 Hub 中**分享** |
| 线程变更后发布最新消息 | 在**分享**子菜单中**更新** |
| 在 Mac 上保留私有离线副本 | **将对话保存为 Markdown**（**⌘⇧S**） |

## 要求

- 必须**登录** Alter。如果已登出，分享会因登录错误而失败。
- 对话必须是正常的 **Hub 聊天**。**Live Notepad** 或 **Meeting Scribe** 操作启动的**会议讨论**无法在 Web 上分享。
- 讨论必须已保存 — 未保存的临时对话不显示分享控件。

## 发布的内容

Alter 上传包含以下内容的包：

- **对话标题**和**完整消息线程**（用户、助手和外部消息）
- **附加到消息的上下文** — 文件、图像、文本选择、应用上下文以及 Mac 上仍可用的其他引用材料
- 在大小限制内打包的**附件文件**

收件人看到该内容的**只读 Web 视图**。他们无法继续聊天或编辑您分享的内容。

<Warning>
  分享会创建**公开链接**。拥有 URL 的任何人都可能查看讨论及其上下文。发布前请检查敏感提示、文件路径和附件。
</Warning>

### 大小限制

Alter 在构建包时强制执行上传限制：

| 限制 | 值 |
|-------|-------|
| 单个附件 | 50 MB |
| 总包大小 | 200 MB |
| 附件数量 | 100 个文件 |

过大或缺失的附件可能在已发布视图中显示为**不可用**，而不是阻止整个分享。

## 分享对话

<Steps>
  <Step title="打开聊天">
    在 **Hub** 中打开对话（侧边栏、标签页或 QuickHub → **在 Hub 中打开**）。
  </Step>
  <Step title="选择分享">
    使用以下任一入口并选择**分享**。
  </Step>
  <Step title="确认">
    阅读确认信息 — *这将创建一个包含讨论及其相关上下文的公开链接。拥有该链接的任何人都可能查看这些内容。* — 然后点击**分享**。
  </Step>
  <Step title="复制并发送">
    成功后，Alter 显示**讨论已分享**并将公开 URL 复制到剪贴板。点击**打开链接**在浏览器中预览，或**完成**关闭面板。
  </Step>
</Steps>

上传进行时，对话框显示**正在分享讨论…**并在请求完成前禁用主按钮。

## 在哪里找到分享

### Hub 侧边栏

在 Hub 历史列表中右键单击对话：

- **分享** — 创建新的公开链接
- **分享**子菜单（已分享时）：
  - **复制链接**
  - **更新**
  - **移除**

### 对话标签菜单

打开标签操作菜单（对话标签上的 ⋯）以访问相同的**分享**项或子菜单。

### 命令面板

在有活动对话标签时打开 Hub 命令面板（Hub 切换器中默认 **⌘K**）。搜索：

| 命令 | 操作 |
|---------|--------|
| **分享对话** | 发布并复制新链接 |
| **复制分享链接** | 复制现有公开 URL |
| **更新共享的对话** | 重新发布最新消息和上下文 |
| **移除共享的对话** | 取消发布链接 |

当活动标签是已保存的对话时，QuickHub 在其切换器中提供相同的分享命令。

## 管理现有分享

首次成功发布后，Alter 会在 Mac 上记住该对话的链接。

### 复制链接

使用侧边栏或标签子菜单中的**复制链接**，或命令面板中的**复制分享链接**。URL 会在不重新上传的情况下复制。

### 更新

当线程变更且您希望查看者看到最新版本时，选择**更新**（子菜单）或**更新共享的对话**（面板）。

**更新会立即重新发布** — Alter 跳过确认对话框，上传当前对话状态并再次复制链接。

### 移除

选择**移除**（子菜单）或**移除共享的对话**（面板）。确认**取消分享？** — *已发布的讨论将被取消发布。*

移除后，公开 URL 应停止工作。Alter 会清除 Mac 上该对话的存储链接。

## 公开链接格式和托管

- 链接在 **alterhq.com** 上提供（例如 `https://alterhq.com/s/...`）。
- Alter 在复制前验证返回的 URL 使用受信任的 Alter 前端主机。
- API 可能返回分享的**过期**时间戳。将链接视为**可撤销但非保密** — 仅与您信任能看到内容的人分享。

移除分享会取消发布讨论；过期行为取决于 Alter 服务器在设置 `expiresAt` 值时的策略。

## 隐私和数据处理

对话分享是**选择加入**，与 Alter 的 local-first 历史**不同**：

| 主题 | 行为 |
|-------|----------|
| 默认聊天存储 | 保留在 Mac 上 — 参见[本地数据和隐私](/zh/references/local-data-and-privacy) |
| Web 分享 | 您明确将讨论包上传到 Alter 服务器 |
| 谁可以查看 | 拥有公开 URL 的任何人（无需 Alter 账户） |
| 发布所需账户 | 必须登录 Alter — 发布与您的账户绑定 |
| 本地链接记忆 | Alter 在应用偏好设置中存储每个对话最后分享的 URL，以便菜单提供复制 / 更新 / 移除 |

不要分享包含密码、财务数据、机密文件或私人会议录音的对话，除非您打算让这些材料在 Web 上可见。

原始聊天期间使用的云模型提供商与分享分开 — 分享上传的是对话快照中的内容，而非完整本地数据库。

## 故障排除

**菜单中缺少分享**

- 会议 **Live Notepad** 和 **Meeting Scribe** 聊天无法在 Web 上分享
- 请先保存对话 — 临时未保存的聊天没有分享控件
- 如果另一个分享对话框或上传正在进行，请等待

**分享因登录错误失败**

- 在**设置 → 个人资料**或账户菜单中登录，然后重试

**分享因包过大而失败**

- 从上下文中移除大附件，或使用**将对话保存为 Markdown** 导出并通过自己的渠道分享文件
- 限制：每个文件 50 MB，总计 200 MB，100 个附件

**复制链接无效果**

- 如果服务器不再有分享，使用**更新**重新发布
- 确认您从最初分享的同一 Mac 复制（链接记忆是本地的）

**我需要支持包，而非公开链接**

- 使用[共享追踪](/zh/workflows/share-task-traces#share-trace)向 Alter 支持上传任务调试信息
